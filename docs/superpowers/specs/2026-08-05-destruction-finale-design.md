# 敵基地破壊のフィナーレ演出

日付: 2026-08-05

## 目的

敵基地はステージのボスだが、破壊演出が雑魚と同種の爆発パーティクルだけで格が出ていない。
閃光・集中線・衝撃波リングを重ねた派手なフィナーレを加える。

## 現状

- `EnemyBase._die()` — `dying = true`、`dyingTimer = 90`（1.5秒）
- `EnemyBase._updateDyingSequence()`（`:109`）— 6フレームごとに機体上のランダムな位置へ
  サイズ20〜50の爆発＋`camera.shake(8, 3)`
- `EnemyBase._finishDestruction()`（`:631`）— `alive = false` にして中心にサイズ80の爆発1発。以上

破壊直後は画面遷移が無い。`!base.alive` になると `main.js:836` がその場に旗を生成し、
プレイヤーが回収しに行く流れなので、演出を見せる尺がある。閃光が晴れたら旗が現れている、
という見せ方になる。

## 決定事項

1. **集中線は画面全体を覆う。** 基地を消失点として、画面対角より長い線を放射状に張る。
   基地が画面端にあれば線の中心も端に寄るが、基地から出ている以上それが自然。
2. **衝撃波リングは見た目＋画面揺れ強化。** リングの拡大に合わせて `camera.shake` を強めに呼ぶ。
   破片やパーティクルを吹き飛ばす案は、破片側との結合が増えるため見送る。

## 設計

### 発火点

`_finishDestruction()`。既存の1.5秒シーケンスが終わった瞬間に、下記3要素をまとめて生成する。

### 3要素

| 要素 | 内容 | 寿命 |
|---|---|---|
| 閃光 | 基地中心の白い発光。爆発の起点を作る | 4〜6 frames |
| 集中線 | 基地を消失点とする放射状の線 40本前後。角度・長さは1本ずつランダム（均等配置に見せない）。線長は画面対角より長く取り、基地が画面のどこにあっても端まで届かせる | 8〜12 frames |
| 衝撃波リング | 半径 0 → 320px。序盤で速く広がり後半で減速。線幅は太→細、不透明度は 1 → 0 | 30 frames |

同時に `camera.shake(20, 24)` を呼ぶ。既存の小爆発が `shake(8, 3)` なので、フィナーレは明確に強い。

### 配置

`src/js/entities/DestructionFinale.js` に3クラスとファクトリ `createDestructionFinale(x, y)` を置き、
`game.particles` に push する。

既存の `update()` / `draw()` / `alive` 契約に乗るので、ゲームループ（`main.js:641` 付近の更新、
`:1070` 付近の描画）もステージ切り替え時のクリア（`GameStateManager.js`）も変更不要。
破片（`DebrisPart`）と同じ相乗り方式。

パーティクルは配列順に描かれるため、フィナーレを最後に push すれば破片や爆発の手前に出る。

## テスト方針

`tests/helpers/fake-ctx.js` で描画呼び出しの幾何を検証する。

- 衝撃波リング: 半径が単調増加する / 不透明度が単調減少する / 寿命で `alive = false` になる
- 集中線: 各線が中心から放射状に伸びている（線の方向が中心からの向きと一致）/
  線長が画面対角以上ある / 本数が想定範囲
- 閃光: 寿命が短い（数フレーム）
- ファクトリ: 3種類すべてを返す
- `EnemyBase._finishDestruction` が `camera.shake` を小爆発より強い値で呼ぶ

## スコープ外

- 衝撃波による破片・パーティクルの吹き飛ばし
- ヒットストップやスローモーション
- 敵基地以外の機体への適用（テンポが落ちる）

## 母艦への適用（2026-08-05 追記）

母艦の破壊にも同じフィナーレを出す。母艦の喪失は残機1のため**必ずゲームオーバー**であり、
ゲーム中で最大の見せ場だから。`Carrier.die()` から同じ `createDestructionFinale()` を呼び、
`camera.shake` も同じ値を使う。

これに伴い、モジュール名を基地専用の `BaseDestructionFx` から中立な `DestructionFinale` へ、
定数の接頭辞も `BASE_FINALE_*` から `FINALE_*` へ改名した。利用者が2つになった以上、
基地専用に見える名前は誤解を招く。

なお母艦の爆発そのものも、体格に対して極端に小さかったため別途拡大している
（粒子25→100、広がり0.6→1.3、フラッシュ半径 9.8→45.5px）。
64x32px と最大の機体なのに、船体を囲む円の 0.27 倍しかフラッシュが無かった。
