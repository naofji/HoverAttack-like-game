# 7面の要塞 段C: 電流の床（ダメージ床）

2026-10-29。親: `2026-09-06-stage7-fortress-design.md`、直前: `2026-10-29-stage7-fortress-rooms-design.md`（室→廊下→室）。
ユーザー指示は「ダメージ床に進んで」。**隔壁扉は未着手**（段Cの残り）。以下の「私の判断」はユーザーの承認を受けていない。

## 何を作ったか

廊下の床を、予兆 → 放電 → 休みの周期で電流が走る。壊せず、間を読んで通るか、上を飛んで避ける罠。
バリアが「撃って開ける門」なのに対し、こちらは「通り方を問う床」。

| 項目 | 内容 |
|---|---|
| 置き場所 | バリアのある廊下の、長いほうの側の床。バリアの列から2列離す。長さ3未満は敷かない |
| 周期 | 予兆30f（火花だけ）→ 放電50f（ダメージ）→ 休み70f。床ごとに位置から位相をずらす |
| 放電の高さ | 20px。廊下は64px、自機は24px。床に降りれば触れ、上を飛べば避けられる |
| ダメージ | 1回5。同じ相手へは15f空ける（放電中は最大4回=20）。触れると上へ弾く（vy -3）で居座れない |
| 対象 | 自機（ドッキング中・無敵中は除く）と母艦。**敵と弾は影響を受けない** |
| 足元の床が壊れたら | そのタイルは放電しない（描きもしない） |
| 音 | 放電に入る瞬間の「バチッ」だけ（連続音にしない）。画面から1画面以上離れた床は鳴らさない |

## 私の判断（承認を受けていない）

1. **置き場所をバリアと同じ廊下にした。** 計画では「廊下ごとに用途を振り分ける」つもりだったが、
   実測（8シード・99階）で**各階の「室に挟まれた廊下」は全階で1本だけ**、それをバリアが使っていた。
   別の廊下は行き止まりの尾（ふつう通らない）しか無い。バリアを減らして譲る案は、
   バリア約10本という既存の手応えを動かすので避けた。
2. **バリアの両側ではなく長い側1つ**にした。比較（8シード）: 3列離し端も空ける=20本（5シードにしか無い）、
   2列離し端を空けない=53本（全シード、1シード平均6.6本・長さ平均4.2）、両側=98本。
   両側だと2階に1つ以上でうるさいので、53本の案にした。数は `ELECTRIC_FLOOR_BARRIER_GAP` / `ELECTRIC_FLOOR_MIN_LEN` で調整。
3. **敵は影響を受けない。** 守備隊が自分の罠で減ると「開けた先に待ち構えている」が崩れる。弾も素通り（バリアとの違い）。
4. **母艦は受ける。** ドッキングしたまま床を滑って抜ける抜け道を作らない（バリアの 2b と同じ理由）。
5. 敵の湧きは電流の床の上と左右1列から外した（バリアと同じ扱い）。他の面には影響しない（7面だけの配列）。
6. 光の滲みは四角いパネルにしない。暗い背景では茶色い箱に見えたので、柱の周りの暈しだけにした。

## 実機で見るところ

| 見るところ | 調整用の定数（`Constants.js`） |
|---|---|
| 予兆を見て放電に備えられるか／放電が長すぎ・短すぎないか | `ELECTRIC_FLOOR_WARN_FRAMES` / `_ACTIVE_FRAMES` / `_REST_FRAMES` |
| 床に降りたとき痛すぎ・軽すぎないか、弾かれ方 | `_TOUCH_DAMAGE` / `_HIT_INTERVAL` / `_KICK_VY` |
| 上を飛んで避けられるか（避けるのが簡単すぎ・難しすぎ） | `ELECTRIC_FLOOR_H` |
| 床の数・長さ（多すぎ・少なすぎ） | `ELECTRIC_FLOOR_MIN_LEN` / `_BARRIER_GAP` |
| 放電の絵（黄色の柱）がバリア（水色）と見分けられるか | `ELECTRIC_FLOOR_COLOR` ほか色 |
| 「バチッ」の音の大きさ | `ELECTRIC_ZAP_GAIN`（A特性 -42.0dB、吸収音より1.7dB上） |

## 実装の置き場

- 生成: `world/fortress.js` の `planZoneContents`（`zone.electricFloors = [{r, c0, c1}]`）、湧きの除外は `Map._placeFortressContents`
- 実体: `entities/ElectricFloor.js`（`game.electricFloors`。`SpawnManager.spawnElectricFloors()`、更新・描画・音は `main.js`）
- 音: `audio/sounds/fortressSounds.js` の `playElectricZap`（オフライン再現は `tools/render-barrier-sounds.mjs` の `zapGen`）
- 絵の確認: `node tools/render-fortress-scene.mjs --seed 3 --zone 2 --phase active|warn|rest`（バリアも一緒に描く）
- テスト: `tests/electric-floor.test.js`（18通りの壊し方で全部赤を確認）
