# 反射ビームの水面反射 設計書

日付: 2026-09-06

## 背景と動機

反射ビーム（`ReflectBeam`）は7面（要塞）の反射ビームキャノンが放つ、地形で跳ね返るレーザー兵器である。
現時点では地底湖（4面）等の水ステージに反射ビームキャノンは登場しないが、将来的なステージ追加や拡張性、また「光は水面で反射する」という物理的リアリティと遊び心から、水面（空気と水の境界面）でも反射するように仕様を拡張する。

## 要件

1. **水面での反射（境界面でのバウンド）**:
   - 空中から水面に侵入しようとしたビームは、水面で跳ね返る（水中に侵入しない）。
   - 水面は水平面であるため、水面への衝突時は鉛直方向の速度（`vy`）が反転し、水平方向（`vx`）は維持される（入射角＝反射角）。
   - 万が一水中にビームが存在し水面へ向かった場合も、全反射として水面境界で跳ね返る。
2. **演出（水面の波紋）**:
   - 水面で反射した際、水面レンダラーに波紋（`addRipple`）を発生させ、光が水面に当たって跳ね返った瞬間を視覚的に演出する。
3. **既存動作との完全な互換性**:
   - 水が存在しないステージ（要塞面など）や、通常の固体壁に対する反射挙動には一切影響を与えない。

## 設計方針

### 1. `beamPath.js` (`stepBeam`)
- ビームにとっての進入不可（衝突）判定 `isBlocked(px, py)` を導入：
  - `map.isSolidAtPixel(px, py)` が true の場合
  - `map.isWaterAtPixel` が存在し、現在地の水状態と移動先の水状態が異なる場合（`isWater(px, py) !== currentWater`）
- これにより、水面境界が固体壁と同様に反射面として機能する。
- 戻り値に `waterBounced: boolean` を含め、水面境界で反射したかどうかを呼び出し元に伝える。

### 2. `ReflectBeam.js`
- `update()` 内で `next.bounced` 時に `next.waterBounced` を確認。
- `waterBounced` が true で環境レンダラーに `addRipple` がある場合、水面に波紋を発生させる（強度 1.5）。

### 3. テスト計画
- `tests/beam-path.test.js`:
  - 空中から水面へ斜めに入ったビームが水面で `vy` を反転させて上空へ跳ね返ること。
  - 水面反射時に `waterBounced: true` が返ること。
  - 水のない通常の壁では `waterBounced: false` であること。
- `tests/reflect-beam.test.js`:
  - 水面を持つステージにおいて `ReflectBeam` が水面で跳ね返り、反射回数（`bounces`）がインクリメントされ、波紋が呼ばれること。
