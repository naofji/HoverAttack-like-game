# 5面の天井のつらら — 設計

日付: 2026-10-11
ブランチ: `feat/stage5-snowtrees`（雪の木の上。木とは別のコミット。木だけ先にマージしたいときは分けられる）

## 目的

5面（雪と氷）の天井に、氷のつららを吊るす。**撃つと少し震えてから落ち、落ちたつららが当たった機体（自機・母艦・敵）にダメージを与える。**
上にいる敵の頭上のつららを撃って落とす攻略の手になり、同時に、自機が下を通るときの危険にもなる。
参考は 3面の町（`2026-10-11-stage3-town-design.md`）と 5面の雪の木（`2026-10-11-stage5-snowtrees-design.md`）。

## ユーザーが決めたこと（2026-10-11）

| 項目 | 決定 |
|---|---|
| 当てる相手 | **自機と敵の両方**（母艦も。範囲ダメージ `applyBlastDamage` と同じ顔ぶれ） |
| 落ちるタイミング | **少し震えてから落ちる（約 0.4 秒）。** 下の機体が避ける余地を残す |
| ダメージ | **つららの大きさに比例（15〜35）。** 自機と敵に同じ数値 |
| 置き場所 | **開始の部屋と基地の部屋を避けて、面全体の天井。** 木と同じ「村」の濃淡で分ける |
| 音 | 最初の段では無音。仕組みが固まってから別の段で足す（A特性で実測するため。3面の町の段 4 と同じ） |

## 作り方（3 面の町の仕組みに載せる）

**案 A を採る:** つららを `Town`（`world/town/Town.js`）の「天井に吊るした壊せる建物」にする。4 面の蔓（`site: 'ceiling'`）と同じ作り。

- 弾・爆風・敵の弾での当たり（`sweepProjectile` / `blast`）、支えの岩が壊れたときに落ちる処理（`onBlockDestroyed` → `_settle`）、置き場所探し（`findSites`）、
  群生（`villages.js`）、置けるかの判定（`placer.js`）が、そのまま使える
- 足すのは 3 つだけ: ① 「もろい」建物の印（`brittle`）、② 落下中に機体へダメージを与える塊（`IcicleFall`。`ToppleTree` と同じく `FallingPiece` の子）、③ 氷の色
- **案 B（地雷のような専用の部品 `game.icicles`）は採らない。** 当たり判定の配線・天井の支え・置き場所を作り直すことになり、`main.js`（約 1200 行。CLAUDE.md が書き足しを避けるよう求めている）にも書き足すため

`map.town` の名前は変えない（弾・爆発・岩の破壊の配線がすべてこの名前を見ている）。5 面の `STAGE_ENVIRONMENTS` の `props` を `'snowtrees'` から **`'snow'`** に改め、
`Map._generateSnow()` が「木の設計図 ＋ つららの設計図」を 1 つの `Town` に載せる。

## つらら（`world/town/icicles.js`）

- 天井から垂れる、先の尖った細い多角形（輪郭は少し揺らし、片側に明るい面、先の方に透ける濃い筋）。**長さ 24〜64px（見える長さ）、根元の幅 8〜12px**
- 上端の 4px は天井の岩に埋まる（4 面の蔓と同じ。支えのかけらを根元の段に必ず持つ）。**かけらは全部 `MAT_ICE`（新しい材料。燃えず・誘爆しない・厚い壁＝弾が止まる）**
- 色は氷の青白（岩の鋼青より明るく、地形の雪のふち `SNOW_CAP_COLOR` より暗く、雪の木の白とは色味で離す）。輝度の縛りは `tests/icicles-palette.test.js`
- 遠景（`CaveBackdrop` の `SPIKE_*_SNOW`）にも氷柱があるが、あちらは奥の層の飾り。手前のつららは遠景より明るく、輪郭がくっきりしているので見分けられる

### 置き場所（`world/town/generateIcicles.js`）

- `findSites` の天井の区間から、`placer.js` の判定（盤面の中・除外の矩形・岩に埋まりすぎない・重ならない）で置く。天井の空き（`run.drop`）から、床まで残す余白（`ICICLE_KEEP_BELOW`）を引いた長さまで
- 除外の矩形は**開始の部屋と基地の部屋の両方**（`Map._reservedRects()` の 2 つとも。木は基地だけ避けている）
- 乱数は派生ストリーム（木 `^0x5E0A71`・4 面の植物 `^0x4F3A57` とは別の `^0x1C1CE5`）だけ。`game.rng` は消費しない（週次の決定性）。濃さは `ICICLE_FILL_SCALE` と村の濃淡

## 震えて落ちる（`Town` の変更）

1. 何かが当たる（`chip`）と、`brittle` の建物は**欠けずに**震え始める（`b.shake = ICICLE_SHAKE_TICKS`）。震えている間の追加の当たりは無視する（震えを延ばさない）
   - 弾・爆風・敵の弾・落ちる破片のどれでも同じ。1 発で必ず震え始める
2. 震えている間は、描くときに ±`ICICLE_SHAKE_AMPLITUDE`px 横に揺らす（描画だけ。当たりと支えは動かさない）。震えの時間は `ICICLE_SHAKE_TICKS`（約 24 tick ＝ 0.4 秒）
3. 震えが終わったら、全体を 1 つの `IcicleFall` として切り離して落とす（`_detach` を全かけらに使う）。建物には何も残らない
4. **支えの岩が壊れたとき**（`onBlockDestroyed`）は、震えずにすぐ落ちる（足場が無くなった時点で吊っていられない）
5. 落ちたつららが別のつららに当たる（落ちる破片が下の建物を欠かす既存の処理）と、そのつららも震え始める（連鎖。1 本ずつ 0.4 秒遅れるので、一斉には落ちない）
6. 落ちている塊が `Town` の落ちる破片の上限（`TOWN_FALLING_MAX`）で追い出されるときは、砕けた氷の粒を出して消える（既存の `_trimFalling`）。震えている最中に支えの岩が壊れたら、4. のとおりそのまま落ちる

## 落下とダメージ（`IcicleFall`、`Town._updateIcicle`）

- 重力と最大速度は既存の落ちる破片と同じ（`TOWN_FALL_GRAVITY` 0.25・`TOWN_FALL_MAX_SPEED` 7）。回さない（先が真下を向いたまま落ちる）。横へも流さない
- **ダメージ:** 塊のかけらが機体の矩形に掛かった tick に、`takeDamage(damage)`。`damage` は長さに比例: 24px で `ICICLE_DAMAGE[0]`（15）、64px で `ICICLE_DAMAGE[1]`（35）。四捨五入。
  対象は自機・母艦・敵（`game.player` / `game.carrier` / `game.enemies`。`applyBlastDamage` と同じ）。**1 本のつららにつき 1 機体 1 回**（落ちている間ずっと当て続けない）
- 当たった機体は、下向きに少し押される（`vy` を `ICICLE_KNOCK_VY` 以上にする。`vx` は変えない。`applyKnockback` は `vx` を上書きするので使わない）。`recordHit` で当たった点を残す（破壊時の破片がその点から散る）
- 当たっても、つららは落ち続ける（機体を貫通する）。**機体に当たったら砕ける**かどうかは実機で見て決める（初案は貫通して床で砕ける。当てられた側が次の 1 本にも当たりうる）
- **着地:** 床か岩に触れたら氷の粒になって砕ける。瓦礫は残さない（4 面の植物と同じ）。下の建物は、ふつうの破片と同じ半径（`TOWN_FALL_CHIP_RADIUS`）で 1 棟 1 回欠かす（雪の木に当たれば欠ける。木の幹が切れれば倒れる）
- 画面外でもシミュレーションは進める（機体に当たるのは画面内のはずだが、止めると状態が食い違う）。粒の注文だけ画面の中に限る（`_flushEffects` の既存の規則）

## 見た目の細部

- 欠け・砕けの粒は氷の欠片（白〜水色、`flora: 'ice'`）。短命で、舞い上がらず、散ってすぐ落ちる（`mode: 'hit'` の控えめな動きを流用する）。穴の縁の暗い色は青灰色
- 震える間は、根元から水滴のような粒を 1 つ落とす（予兆。粒だけ。数 tick おきに 1〜2 個）

## 設計図の印と調整用の定数（`Constants.js`）

| 定数 | 初案 | 意味 |
|---|---|---|
| `ICICLE_LENGTH` | `[24, 64]` | 見える長さ（px。4px 刻み） |
| `ICICLE_WIDTH` | `[8, 12]` | 根元の幅（px） |
| `ICICLE_DAMAGE` | `[15, 35]` | 長さに比例（短い → 長い） |
| `ICICLE_SHAKE_TICKS` | `24` | 震える時間（0.4 秒） |
| `ICICLE_SHAKE_AMPLITUDE` | `1` | 揺れる幅（px） |
| `ICICLE_KNOCK_VY` | `2` | 当たった機体の下向きの押し |
| `ICICLE_FILL_SCALE` | `1` | 村の濃さに掛ける |
| `ICICLE_KEEP_BELOW` | `3` | 床まで残す余白（タイル） |

初案の数値は、実機で見て調整する前提の出発点。濃さは、最初は木の半分くらいの本数（面全体で 150〜250 本）を狙い、実測してコメントに残す。

## 段の分け方

- **段 1（この spec の範囲）:** 設計図（絵・置き場所）、震えて落ちる、ダメージ、着地、連鎖、テスト、`tools/render-town-scene.mjs --stage 5` で PNG
- **段 2（別の spec/plan）:** 音。震え（小さな氷のきしみ）・落下（風を切る短い音）・着地（氷の砕ける音）。`audio/sounds/` に足し、A特性で実測する

## テスト

3 面の町・5 面の木と同じ流儀（`tests/icicles-*.test.js`）。各テストは壊して赤くなることを確認する。

- **絵:** 長さ・幅が範囲に収まる（数千通りの乱数）／かけらは全部 `MAT_ICE` の厚い壁／根元の段に支えがある／輪郭が外接矩形に収まる／色が輝度の縛りを守る
- **置き場所:** 天井にだけ置く／開始の部屋と基地の部屋に掛からない／天井から床まで `ICICLE_KEEP_BELOW` を残す／重ならない／同じ乱数なら同じ設計図／`Math.random` を使わない／`game.rng` を消費しない／村の濃淡
- **震えて落ちる:** 当たっても欠けずに震え始める／震えの間の追加の当たりは時間を延ばさない／`ICICLE_SHAKE_TICKS` 後に 1 つの塊になって落ちる／支えの岩が壊れたら震えずに落ちる／連鎖（落ちたつららが別のつららを震わせる）／描画の揺れは当たりを動かさない
- **ダメージ:** 長さに比例（24px で 15・64px で 35、中間は線形）／自機・母艦・敵のすべてに当たる／画面外の機体にも当たる／1 本につき 1 機体 1 回／当たった機体が下へ押される／`vx` は変わらない／死んでいる機体・ドッキング中の機体の扱い（`takeDamage` の既存の規則に任せる）
- **着地:** 床で砕けて粒を出す／下の建物を 1 棟 1 回だけ欠かす／瓦礫を残さない
- **5 面の組み込み:** `props: 'snow'` で木とつららが 1 つの `Town` に載る／木の設計図は前と同一（指紋で確認）／決定性（`MapDeterminism`）／4・6 面は変わらない
