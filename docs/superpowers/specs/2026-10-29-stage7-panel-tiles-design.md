# 7面の要塞 段B — タイルの絵（金属パネル・装甲板）

2026-10-29。親は `2026-09-06-stage7-fortress-design.md`（段B）。ユーザーの指示は「段Bの金属パネルの絵から始めて」。

## 実態の確認（設計書の想定との差）

設計書は「区画内の通常岩・硬い岩を金属パネルに描き分ける」と書いていたが、段Aの実機調整（床を金属1層、外壁を金属＋右だけ硬い岩）を経て、
**区画の中に通常岩は無い**。7面の seed 1〜3 で区画の印（`map.fortress`）が立つタイルは 金属 約640〜750 / 硬い岩 約120〜150（右壁）だけ。
金属はすでに `_drawPolishedBlock` で光る板として描かれていたが、**1タイルごとに4辺へ面取りが付き、並べるとボタンの格子に見えた**。

したがって段Bの中身は次の2つ。

1. 金属を「板」に見せる（面取りを空洞に面した辺だけにして、接合部は継ぎ目にする）
2. 区画の中の硬い岩（右壁＝弱点）を、金属と見分けがつく装甲板にする

## 決めたこと（私の判断。ユーザーと詰めてはいない）

- 絵は `world/panelBlocks.js`（純関数、`fillRect` しか使わない）。`Map._drawTile(ctx, r, c)` を新設して、全面の描き直しと壊した周りの描き直しの両方がここ1か所で振り分ける
  （以前は同じ振り分けが2か所に重複していた）。振り分け: 壊せない装甲＝磨かれた板（`_drawPolishedBlock`、地形の縁。変更なし）／金属＝`drawMetalPanel`／
  **印の立った硬い岩＝`drawArmorPanel`**／それ以外＝岩。印を使うのは、硬い岩は6面などの区画の外では普通の岩のままだから
- 金属: 空洞に面した辺だけ面取り（光は左上）。接合部は暗い溝＋明るい線の継ぎ目。継ぎ目は縦方向はタイルの境ごと、横方向は2タイルごとに**行ごとに半枚ずらす**（レンガ積み）。
  壁が2枚幅でも床が1枚高でも「板の寸法がタイルより細かくならず、継ぎ目が揃って格子に戻らない」。圧延の筋・リベット・タイルごとの明るさのむらを足す。
  焼け（赤茶へ寄る＋艶が飛ぶ）は従来どおり。ひび割れは描かない
- 装甲板: **艶を出さない**（金属と見分ける決め手）。中央の凹み・四隅のボルト。被弾はひび（1回2本、最大4本）。ゲームでは HP 3 なのでダメージは最大 2＝4本
- 壊れて露出が変わると、隣が描き直される（既存の `invalidateTileRegion`）ので、穴の縁には面取りが付く
- 壊せない装甲（`BLOCK_INDESTRUCTIBLE`、地形の縁）の絵は変えない。`_drawPolishedBlock` から金属の焼けの処理を外した

## 検証

- `tools/render-fortress-scene.mjs`（新設）で PNG に書き出して見た。`--damage "行,列,ダメージ;..."` で焼け・ひびも見られる
- `tests/panel-blocks.test.js`（新設）: 振り分け（実際の7面の全面描き直しで数える）・露出の4辺・継ぎ目の段違い・焼けと割れ・全画素が塗られる。
  15通りの壊し方で全部赤になることを確認済み（最初は3つ生き残り、ひびの上限と Map→パネルの露出・ダメージの対応を足して殺した）
- **面1〜4・6 の絵が変わっていないこと**: `terrain-shape-drawing-invariance.test.js` の基準線は7面を含んでいたので、7面を外した。
  新しい基準線は、この変更の前のコード（HEAD の別 worktree）に `digestDrawing(levels)` の変更だけ重ねて記録し、変更後のコードでも同じハッシュになることを確認した
  （`cache 0188f628…` / `damaged f362b81d…`）

## 実機で見るところ（Cmd+Shift+R）

| 見るところ | 場所 |
|---|---|
| 金属が「1枚の板」に見えるか。継ぎ目の間隔（2タイル）・暗さ | `panelBlocks.js` の `PLATE_LEN`・継ぎ目の不透明度 |
| 岩・遠景の機械と見分けがつくか、地形として暗すぎないか | `drawMetalPanel` の面取りの不透明度、`COLOR_METAL_BLOCK` / `METAL_BLOCK_TINT` |
| 右壁（装甲板）が金属と見分けられ、「弱点」に見えるか | `drawArmorPanel`（凹み・ボルト）、`HARD_BLOCK_TINT` |
| 焼けた金属の赤茶が「熱」に見えるか（従来どおりのはず） | `METAL_HEAT_COLOR` / `METAL_HEAT_GLOSS_LOSS` |
