# 7面: 施設エリア（メタルパネルの地面・壁と金属の斜面）

2026-10-31。親: `2026-09-06-stage7-fortress-design.md`。形の仕組み: `2026-10-27-tile-shape-collision-design.md`。

## 何のためか

7面の「要塞の基地」の雰囲気を強める。今は要塞の区画（最大4つ）の外は、ふつうの洞窟の岩のまま。
その外側の地形にも、メタルパネルで覆われた地面・壁と、凸凹の岩ではない**金属加工の斜面**を設ける。

## 決めたこと（ユーザーの判断）

| 論点 | 決定 |
|---|---|
| どこに | **要塞の区画の外の地形**。区画の中（室・廊下・バリア・電流の床・守備隊）は触らない |
| 硬さ | **混ぜる**。大半は見た目だけ金属（硬さは今のまま）、一部だけ本物の金属 |
| 本物の金属（HP 6）にする所 | **(b) 斜面と、施設エリアの外周の帯（1層）** |
| 斜面での自機 | **滑り落ちない**（雪の面のような滑りは無し） |
| 斜面でのグレネード | **転がり落ちる** |

## 作り

### 1. 施設エリアを置く

- 区画の外に矩形の**施設エリア**を置く。区画（と区画の外周の余白）、開始の部屋、基地の部屋とは重ねない
  （`_reservedRects()` と `fortressZones` を除外）
- 置き方は**派生ストリームの乱数**（`CaveBackdrop`・雪の階段と同じ）。`game.rng` を消費しないので週次の決定性は保たれる
- 生成の順は、要塞の区画（Step 9a）のあと。区画が先に場所を取る
- 初期値（私の案。実測して調整）: 個数 8、幅 10〜20、高さ 8〜14 タイル。置けなければ少なくてよい

### 2. エリアの中の中身

| 元の中身 | 硬さ | 絵 |
|---|---|---|
| 通常の岩 | 1発（今のまま） | **艶のない薄い板**（新しい絵）。本物の金属と見分けられること |
| 硬い岩 | 3発（今のまま） | 装甲板（`drawArmorPanel`。区画の右壁と同じ絵） |
| 外周の帯（矩形の縁の1層にある岩） | **本物の金属に置き換え（6発）** | 今の艶のある金属パネル（`drawMetalPanel`） |
| 斜面（下の3） | **本物の金属に置き換え（6発）** | 金属パネルの斜面（新しい絵） |

- 外周の帯は「縁に掛かった岩だけ」を金属にする。縁が空洞を通る所は空洞のまま（壁を新しく建てない）。
  エリアに入る道はふさがない
- 空洞は作らない・埋めない（下の階段を除く）。洞窟の通り道は今のまま

### 3. 金属の斜面

- 洞窟の地形には、1段ずつの階段がほとんど無い。そこで**エリアの中に金属の階段を盛る**
  （5面の `carveSnowStairs` と同じ考え方。段数・本数は定数）。盛った段を本物の金属にする
- 7面に新しい形の規則（例: `'metalSlope'`）を足す。**施設エリアの中のタイルだけ**、
  `snowSlope` と同じ条件で段を45度の斜面にする。本物の金属（今は「磨き仕上げ＝削らない」扱い）も、
  エリアの中なら削ってよい
- エリアの外の洞窟の岩、区画の中は今のまま四角
- **（私の判断）8px の小さい面取りは付けない。** 加工された金属の見た目にするため、45度の斜面だけにする
- **滑り:** 7面の環境は `kind: 'none'` で `motion.slide` が 0。`_applySlope` は slide が 0 だと何もしないので、
  自機・アタッカー・戦車は斜面で滑らず、上りで遅くもならない（コードを足さずに満たせる。テストで縛る）
- **グレネード:** `stepGrenade` はどの面でも形の斜面（`slopeHitAlong`）で跳ねて転がるので、そのまま転がり落ちる
  （テストで縛る）

### 4. 描画

- 薄い板と金属の斜面の絵を `world/panelBlocks.js` に足す（`fillRect` と多角形だけ。`tools/render-fortress-scene.mjs`
  の PixelCanvas で描けること）
- 斜面のパネルは、斜辺に沿って面取りの明るい線を引く（光は左上から。今のパネルと同じ）
- 壊れたときは、今の形の作り直し（`shapeAfterBreak`）と露出の描き直しがそのまま効く

## 私の判断（未承認）

1. エリアの個数・大きさの初期値（8 個、10〜20 × 8〜14）
2. エリアの中に金属の階段を盛る（盛らないと斜面がほとんど出ない）
3. 8px の小さい面取りは付けず、45度の斜面だけにする
4. 通常の岩は「艶のない薄い板」の新しい絵にし、本物の金属と見分けられるようにする

## 実機で見るところ

| 見るところ | 調整用の定数 |
|---|---|
| 基地らしく見えるか・施設の量 | エリアの個数・大きさ（新しい定数） |
| 本物の金属の量（外周の帯と斜面）で、掘り進むのが重すぎないか | 外周の帯の有無、階段の本数・段数 |
| 薄い板（1発）・装甲板（3発）・金属（6発）が見分けられるか | `panelBlocks.js` の絵 |
| 斜面を歩いて滑らないか、グレネードが転がり落ちるか | — |
