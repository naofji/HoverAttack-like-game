# 3面の壊せる町並み — 設計

日付: 2026-10-11
ブランチ: `feat/stage3-town`

## 目的

3面に、敵ではない「壊せる町並み」を面全体に置き、撃つと欠け・燃え・崩れ落ちる
「破壊の美」の面にする。洞窟の中の町として、3面の黄色系の岩（DarkGoldenrod `#B8860B`）に
合う絵柄にし、単純な繰り返しに見えないようにする。

### ユーザーが決めたこと（2026-10-11 のブレインストーミング）

| 項目 | 決定 |
|---|---|
| 遊びへの関わり | **見た目だけ。** 機体は建物をすり抜け、弾も止まらない。スコア・タイムに影響しない |
| 壊せる攻撃 | **敵味方どちらでも。** 敵の流れ弾や爆発でも町が勝手に焼けていく |
| 置き場所 | **床に建つ建物・壁に張り付く住居・天井から吊るもの**の3種すべて |
| 壊れ方 | **段階で壊れる。** 当たった所が欠け、上の階だけ落ちるなど建物ごとに崩れ方が変わる。焦げた骨組みと瓦礫が残る |
| 密度 | **面全体にまんべんなく** |
| 絵柄 | **A（日干し煉瓦の塔の町）と C（坑道の町）の混合。** 広い所は A 多め、狭い所は C 多め |
| 支えの岩が壊れたら | **崩れ落ちる**（見た目だけの破片。当たっても痛くない） |
| 延焼 | **燃え移る。** 木は燃え移りやすく、土は燃えにくい。火は時間で消える |
| 音 | **崩れる音＋炎の音**（どちらも手続き合成。A特性で既存の音と合わせる） |
| 作り方 | **建物1棟ごとに小さな canvas ＋「支えにつながっているかけらだけが残る」規則** |

絵柄の参考（2026-10-11 に調べたもの）:
- A: シバーム（イエメン。下が太く上が細い日干し煉瓦の高層住宅、上の階ほど窓が多い、上階を白く塗る、
  塔の上の階どうしを橋や綱でつなぐ）、メサ・ヴェルデのクリフ・パレス（崖のくぼみに詰まった砂岩の家、
  四角い塔・丸い塔、壁から突き出た梁）
- C: 鉱山町（木の骨組みの小屋、錆びたトタン屋根、足場と梯子、配管、ランタン）

## 全体の形

```
Map._generate()  ──(派生乱数)──▶ buildTown() ──▶ map.town (Town)
                                                   │
main._simulationTick() ── map.update() のあと ──▶ town.update(game)
                                                   │  ├ 飛んでいる弾・ビームと建物の当たり
                                                   │  ├ 落ちる破片の移動・着地
                                                   │  └ 火（6フレームに1回）
SpawnEffects.spawnExplosion(x, y, size) ────────▶ town.blast(x, y, size)
Map.damageBlock()（岩が壊れたとき）──────────────▶ town.onBlockDestroyed(r, c)
main._drawWorld()  遠景 → env.drawBehindTerrain → town.draw(ctx) → map.draw → 機体…
```

- 町は Map が持つ（`map.town`）。遠景（`map.backdrop`）と同じ扱いで、タイトルのデモで3面が
  流れたときにも町が出る。町の無い面では `map.town` は `null` で、呼び出し側はすべて
  `town?.` で黙って飛ばす
- 描画は**遠景と地形のあいだ**。土台は岩の縁の奥に隠れ、機体・弾・爆発は必ず建物より手前に出る。
  炎と煙も同じ層に描き、岩の縁より手前に出さない
- 落ちた破片が砕けたときの粒と土煙は、爆発と同じく `game.particles`（地形より手前）に足す

### 面の指定

`Constants.js` の `STAGE_ENVIRONMENTS` の3面の行に `props: 'town'` を足す。ほかの面の行には
足さない（無ければ町なし）。あとで別の面にも置きたくなったら、この1語を足すだけで済む。

## 1. 置き場所と生成

### いつ・どの乱数で

`Map._generate()` の最後、遠景（`CaveBackdrop`）と同じところで作る。乱数は
`new SeededRNG((this.game.rng.state ^ <町用の定数>) >>> 0)` の派生ストリームを使い、
**`game.rng` は消費しない**（週次の決定性を守る。`CaveBackdrop` と同じ作り）。

### 置き場所（1タイル刻みで地形を調べる）

- **床**: 上が空いた床タイルが同じ高さで続く区間。段差で区間を切る
- **壁**: 横が空いた岩の面が縦に続く区間。そこに張り付く家（A は梁で張り出した家、C は足場の上の小屋）
- **天井**: 下が空いた天井。2点のあいだに渡す吊り橋、ランタン、吊るした小屋

### A と C の割合

その場所の**天井までの空き**で決める。空き 12 タイル以上で A 8割、5 タイル以下で C 9割、
あいだは線形に補間する（`TOWN_ADOBE_SHARE_*`）。

### 置かない場所・高さの上限

- 基地の部屋（`_reservedRects()` の2つ目）にだけ置かない。基地のパルスや砲台を見やすくしておくため
- 開始の部屋には置く（面に入った瞬間に町だと分かるように）
- 建物の最上部は天井から 2 タイル以上離す（`TOWN_CEILING_CLEARANCE`）

### 繰り返しに見せない部品の組み合わせ

- **A の塔**: 階数 2〜9、幅、上に向かって細る具合（4px の段）、白壁の高さ、屋上（凹凸・平ら・丸屋根）、
  窓の並び（上の階ほど多い）、突き出た梁、バルコニー、外階段、隣の塔への橋、まれに丸い塔
- **C の小屋**: 単独・積み重ね・高床、屋根（片流れ・切妻・トタン）、板の向き、看板、煙突、配管、梯子、足場

### 色

- A は土色5色前後＋白壁＋灯り、C は木3色＋錆3色（`town/palette.js`）
- **建物の色はすべて「遠景（`backdropColors` の rockLight）より明るく、地形の岩（`STAGE_PALETTES[2].fill`）
  より暗い」範囲に収める。** 輝度の上下限をテストで縛る（`tests/cave-backdrop.test.js` と同じ考え方）
- 窓の灯りは**弾と見間違えないよう、くすんだ琥珀色の四角で光らせない**（弾は明るい黄色
  `#FFDD33` / `#FFCC00` の丸）

### 描き方

建物の絵は **`fillRect` だけ**で描く（細る塔も 4px の段）。理由は2つ。
地形の一番細かい描き込み（4px）と揃うこと。`tools/render-water-scene.mjs` と同じく node で
PNG に書き出せること。

### 生成時間

数百棟の canvas を作るので、面の読み込みにかかる時間を実測する。目標は 100ms 以内。

## 2. 壊れ方（かけら・支え・落下）

### 建物の持ち方

建物1棟 = 自分の canvas（絵）＋ 4px 角のかけらの表（`Uint8Array`。0=無し、それ以外=材料と状態）。
支えのかけら（床・壁・天井の岩に接するもの）には、支えている岩タイル `(r, c)` を記録する。

### 何が当たると欠けるか

| 当たるもの | 欠け方 |
|---|---|
| 飛んでいる弾（`game.projectiles` と `game.enemyBullets`。マシンガン・ミサイル） | **最初に入った建物を1回だけ**欠かせ、弾は飛び続ける（弾に印を付ける）。前フレームの位置から今の位置までを 4px 刻みで調べ、速い弾が薄い所をすり抜けないようにする。欠ける半径は弾の種類ごとの表 `TOWN_PROJECTILE_CHIP`（マシンガン約4px、ミサイル約10px） |
| 爆発 | `spawnExplosion(x, y, size)` から `town.blast(x, y, size)`。半径 = `TOWN_BLAST_RADIUS_K`(3.3) × √size（マシンガンの着弾 4粒→約7px、ミサイル 36粒→約20px、グレネード 150粒→約40px）。ミサイル・グレネード・機体の破壊・地雷・基地が全部ここを通る |
| 反射ビーム | 通り道（`segments()`）にある建物を、1発につき1棟1回ずつ欠かせる |
| 落ちる破片 | 下の建物に当たると、当たった所を欠かせる（連鎖） |

- 穴の縁はぎざぎざにし（半径の境目のかけらを確率で残す・余分に削る）、縁を焦げ色にする
- 描き直しは、その建物の消えたかけらを `clearRect` で抜き、縁を塗るだけ。建物全体は描き直さない
- **町自身の爆発（崩壊の演出）は `town.blast` に戻さない。** 戻すと崩壊が隣を崩す連鎖が止まらなくなる。
  連鎖は落ちる破片と火に任せる

### 支えの規則

> 支えのかけらから塗りつぶし探索して、つながっているかけらだけが残る。
> つながらない塊は、その形のまま「落ちる破片」になる。

- かけらが欠けるたびに、その建物だけ探索し直す（1棟は多くても数百かけら）
- 岩が壊れたら `Map.damageBlock()` の「壊れた」分岐から `town.onBlockDestroyed(r, c)`。その岩に支えられていた
  かけらは支えを失い、同じ探索で落ちる。`env.renderer.onBlockDestroyed` と同じ形の通知にする
  （`destroyArea` も `damageBlock` を通るので、1か所で足りる）

### 崩壊

残ったかけらが元の 4割（`TOWN_COLLAPSE_FRACTION`）を下回ったら崩壊する。
- 爆発の閃光と粒を出す（町の音を鳴らし、爆発音は鳴らさない）
- 下の1〜2段（`TOWN_RUIN_ROWS`。A は土台の壁、C は焦げた柱）だけを残し、残りは全部落ちる破片にする
- 残った土台が「焦げた骨組み」になる

### 落ちる破片

- 重力で落ちながら回る。燃えていれば燃え続ける
- 描画の補間に乗せる（前フレームの位置を持つ。`utils/renderInterp.js` と同じ扱い）
- 岩に当たったら砕ける。破片の粒・土煙を `game.particles` に、崩れる音を鳴らし、床に瓦礫の山を残す
  （瓦礫は町の層に描き足す。重なったら1つにまとめる）
- 同時に落ちている破片は 24 個まで（`TOWN_FALLING_MAX`）。超えたら古いものから土煙になって消える

### 画面の外

壊れること・落下・燃え広がりは画面の外でも計算する。粒・土煙・炎・煙は、画面の中かそのすぐ外
（`VIEW_CULL_MARGIN`）で起きたときだけ出す。

## 3. 火

### 材料の表 `TOWN_MATERIALS`

| 材料 | 使う所 | 火のつきやすさ | 燃える速さ | 燃え移りやすさ |
|---|---|---|---|---|
| 木 | C の板、A の梁・バルコニー・窓枠・橋 | 高い | 速い | 高い |
| 土 | A の壁 | 低い | 遅い（くすぶる程度） | 低い |
| 金属 | トタン・配管・ランタン | 燃えない（熱で焦げる） | — | 燃え移りを中継しない |

### 火がつく

- 爆発: 半径の中の燃える材料には必ずつく
- 弾: 確率でつく（初期値は木 15%・土 3%。実機で詰める）
- 火元は当たったかけらにつく。1棟あたり 4 つまで（`TOWN_FIRES_PER_BUILDING`）

### 燃え進む

かけらは「そのまま → 焦げ → 崩れて落ちる」の順に進む。
- 火元は材料に沿って隣のかけらを少しずつ焦がす
- 焦げたかけらは暗い色になるが、まだ支える
- 焦げたかけらは確率で崩れて抜ける。抜けて支えが切れれば、支えの規則どおり上が落ちる
  （燃えた家がやがて自分から崩れる）

### 燃え移る

- 燃えているかけらから 8px 以内に別の建物のかけらがあれば、相手の材料の燃え移りやすさに応じた確率で、燃え進みの計算のたび（`TOWN_FIRE_TICK` ごと）に燃え移る
- 燃えている破片は、落ちた先の建物に燃え移る

### 止まる仕組み（1発で町全体が燃え尽きないように）

- 火元ごとに燃料（秒）を持ち、尽きたら消える（初期値は木 12〜20秒・土 5〜8秒）
- 面全体で同時に燃える火元は 60 まで（`TOWN_FIRES_MAX`）。上限のあいだは新しく火がつかない
- 燃え尽きた土台と瓦礫は、細い煙と残り火をしばらく出してから静かになる
- 燃え進みは 6 フレームに1回だけ計算する（`TOWN_FIRE_TICK`）
- 燃料・燃え移りの間隔は**シミュレーションのフレーム数**で数える（表の「秒」は 60 フレーム＝1秒で換算）。
  物理と同じ速さで燃えればよく、ドック補給のように実時間を守る必要は無い（normal の 0.8x では少しゆっくり燃える）

### 見た目

- 炎: 火元から立ち上がる専用の粒。角ばった塗りつぶし、赤 → 橙 → 黄、ちらつく
- 煙: `smokeSprites` を小さく薄くして使う
- 火の周りをほんのり明るくする（`lighter` 合成）かは、描画の重さを実測してから決める

### 乱数

壊れ方と火は見た目だけなので `Math.random` で構わない（敵の挙動や地形に影響しない）。

## 4. 音（`src/js/audio/sounds/townSounds.js`）

| 音 | 作り | 鳴るとき |
|---|---|---|
| `playTownCollapse(size, sourceX)` | 低い地鳴り（ローパスしたノイズ、尾 約1.2秒）＋瓦礫のガラガラ（短いバンドパスのノイズを 0.6 秒にばらまく）。`size` で大きさと長さを変える | 建物の崩壊、落ちた破片が砕けたとき（小さい破片なら小さく） |
| `startTownFire(intensity, sourceX)` / `stopTownFire()` | `_loopSound('townFire', {build, tune})`。低いゴーッ（ローパスしたノイズ）＋パチパチ（まばらなクリックを並べたバッファをループ、ハイパス） | 画面の近くに火元があるあいだ。強さは近い火元の数と画面中央からの距離 |

- 左右と距離の減衰は爆発と同じ `_out(sourceX)`
- 80ms 以内に続いた崩れる音は1つにまとめ、大きいほうを鳴らす（`TOWN_COLLAPSE_SOUND_MERGE_MS`）
- **音量は A特性で実測して縛る。** 目安: 崩壊は大きい爆発より 3dB 小さく、破片が砕ける音は小さい爆発より小さく、
  炎のループは最大でもバリアの唸り（-48dB）以下
- 新しい `play*` / `start*` / `stop*` は引数なしで呼んでも例外を投げない（`tests/audio-manager.test.js`）
- 効果音は SE バスを通す（`tests/se-bus.test.js` が見張る）

## 5. 描画の重さ

- いまの描画＋更新は 1.395ms（予算の 8.4%）。**町の描画は一番重い場面（燃えている町の真ん中）でも 1ms 以内**を目標にする
- 画面内の建物だけ drawImage する（`isInView`）。落ちる破片も同じ
- 弾と建物の当たりは 64px 角のマス目に建物を登録して引く（総当たりにしない）
- メモリは建物 300 棟で約 4MB の見込み
- 実機での計測は JSON に記録する（画面に出して読ませない）。建物1棟あたり・火元1つあたりに正規化し、分位点と最大値を残す

## テスト（`node --test`）

| 何を | どう確かめる |
|---|---|
| 生成の決定性 | 同じ週なら同じ町。町を作っても `game.rng` の状態が変わらない（`tests/MapDeterminism.test.js` に追加） |
| 置かない場所・高さ | 基地の部屋に建物が無い。最上部が天井から 2 タイル以上離れている |
| A / C の割合 | 複数の週で、天井までの空きごとに A と C を数える |
| 色 | 全部の色が遠景の rockLight より明るく、地形の岩より暗い |
| 支え | 中ほどを抜くと上だけ落ちる。土台の岩を壊すと丸ごと落ちる。4割を下回ると崩壊して土台が残る |
| 弾 | 建物を1回だけ欠かせ、弾の `alive` は変わらない。速い弾が薄い建物をすり抜けない |
| 爆発 | 半径が粒子数から決まる。`spawnExplosion` を通った爆発が建物に届く。町自身の爆発は戻ってこない |
| 火 | 木には燃え移り、土には燃え移りにくい（何度も試して数える）。燃料が尽きると消える。上限 60 を超えない |
| 落ちる破片 | 下の建物に当たると欠かせる。上限 24 を超えない |
| 音 | 崩壊1回で1回鳴る。80ms 以内はまとまる。相対 dB を A特性で縛る |

テストを書いたら、わざと壊して赤くなることを1つずつ確かめる。壊しても赤くならないときは、
テストを直す前に「その壊し方で差が出る fixture か」を疑う。

## 作る順番（段ごとに実機で見てもらう）

1. **段1: 町を置いて描く（壊れない）。** 置き場所・A/C の組み立て・色・描画。ここで絵柄と密度を実機で見てもらう
2. **段2: 欠け・支え・落下・崩壊・瓦礫**
3. **段3: 火**（つく・燃え進む・燃え移る・消える。炎と煙の見た目）
4. **段4: 音**

各段で、調整用の定数と確認ポイントの対応表を付けて渡す。確認のときはハードリロード（Cmd+Shift+R）が要る。

## 範囲に入れないもの

- 町を壊したことによるスコア・実績・表示
