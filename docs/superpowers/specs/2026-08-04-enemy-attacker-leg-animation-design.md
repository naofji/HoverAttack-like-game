# 敵アタッカー 脚アニメーション刷新 設計書

日付: 2026-08-04
対象: `src/js/entities/EnemyAttacker.js`

## 背景と目的

プレイヤー機は股関節→膝→足首の3点ポリラインで脚を描画し、接地時は4フレームの
2足歩行サイクル、空中では横速度に比例して脚が後方へなびく振り子挙動を持つ
(`src/js/entities/Player.js:577-681`)。

一方 EnemyAttacker の脚は `fillRect` 2枚（腿・脛）を横オフセットでずらすだけの
簡易描画で、ロボットとしての説得力に欠ける (`src/js/entities/EnemyAttacker.js:1093-1129`)。

歩行フレームを進める状態機械 `_updateWalkAnimation()`
(`src/js/entities/EnemyAttacker.js:212-224`) は既にプレイヤーとほぼ同一のものが
存在するため、**本作業は描画層のみの置き換え**であり、AI・物理・当たり判定には
一切手を入れない。

目的は、4種すべての敵アタッカーに機体ごとの個性を保ったまま関節脚アニメーションを
与えること。

## スコープ

### 対象

- `EnemyAttacker` の脚描画（`_drawLegs` / `_drawLeg` / `_drawArtilleryLegs`）の全面書き換え
- 型別の脚スタイル定数の追加
- 脚描画に対するユニットテストの新規追加

### 対象外

- AI ロジック、移動・物理、当たり判定（`width`/`height` は不変）
- `Constants.js` の敵設定（`ENEMY_ATTACKER_*` の各 config）
- 胴体・頭部・武器・バックパック・ホバー排気の描画
- `_updateWalkAnimation()` のタイマー閾値（現行の 5 を維持する。heavy と rival で
  移動速度が 2.4 倍違うため、プレイヤーの 4 に揃える必然性がない）
- Player 側の実装（共通化は行わない。理由は「共通化しない判断」節を参照）

## 共通の描画基盤

すべての型で以下の描き方を共有する。

- 1本の脚は「股関節 → 膝 → 足首」の3点ポリラインを `ctx.stroke()` で描く。
  `lineCap` / `lineJoin` は `'round'`。
- 足裏は足首を原点に `ctx.translate` してから `fillRect` で描く。空中では
  振り子角に応じて `ctx.rotate` する。
- 手前脚は `config.bodyColor`、奥脚は `config.headColor` を使い、奥行きを出す。
  プレイヤーのようなグレー固定にはせず、機体色を維持する。
- 描画は既存 `draw()` が確立したローカル座標系（左右反転済み、`crouchOffset` 平行移動済み）
  の内側で行う。既存の呼び出し位置・引数はそのまま。

### 空中の振り子（共通ロジック）

プレイヤーの `_drawHoverLegs` / `_drawSingleLeg` (`src/js/entities/Player.js:611-666`)
に準拠する。

1. 進行方向ローカルの横速度を求める: `localVx = facingRight ? vx : -vx`
2. `±this.maxSpeed` でクランプし `this.maxSpeed` で正規化 → `swing`（-1〜+1）
   - プレイヤーは定数 `PLAYER_MAX_SPEED` で割るが、敵は型ごとに最高速が違う
     （heavy 0.5 / rival 1.20）ため `this.maxSpeed` を分母にする。これがないと
     rival は常に振り切れ、heavy はほとんど振れない。
   - `this.maxSpeed` は config 由来で常に正の有限値なので 0 除算は起きない。
3. 股関節を中心に、膝・足首の基準座標を `swing × maxSwing` だけ2次元回転させる。
4. 足裏はさらに `swing × maxSwing / 1.5` だけ回転させる。
5. 左右で位相をずらす。奥脚は `swing × 0.8 - phaseOffset` を使い、左右がぴったり
   揃わないようにする。

`maxSwing` と `phaseOffset` は型別パラメータ（後述）。

## 型別パラメータ

描画専用の値なので `Constants.js` には置かず、`EnemyAttacker.js` のモジュール
スコープに `LEG_STYLES` 定数として定義し、`this.config.name` で引く。

| キー | 意味 |
|---|---|
| `hipFar`, `hipNear` | 奥脚・手前脚の股関節 X 座標 |
| `lineWidth` | 脚の太さ |
| `footW`, `footH` | 足裏の寸法 |
| `maxSwing` | 空中の最大振り子角（ラジアン） |
| `phaseOffset` | 奥脚の位相ずらし量 |

未知の `config.name` が来た場合は `standard` のスタイルにフォールバックする。

## 型別デザイン

### standard（`#55CCDD` / speed 0.9）— 汎用機

プレイヤーとほぼ同形。「兄弟機」に見えることを狙う。

- 股関節 奥 7 / 手前 10、`lineWidth` 3、膝は前折れ
- 足裏 5×2
- `maxSwing` = 45°（`Math.PI / 4`）、`phaseOffset` = 0.2

歩行ポーズはプレイヤーの4フレーム表 (`src/js/entities/Player.js:668-681`) を移植する。

```text
frame 0 → { near: 0, far: 1 }
frame 1 → { near: 2, far: 3 }
frame 2 → { near: 2, far: 2 }   // 直立・停止時のポーズ
frame 3 → { near: 3, far: 2 }
```

ポーズ番号 0〜3 の膝・足首座標もプレイヤーの `_drawSingleLeg` の `switch` から移植する。

### heavy（`#44AA44` / speed 0.5, jumpForce -5.0）— 重装甲

どっしり踏みしめる歩き方。

- 股関節を外に開き 奥 6 / 手前 11（がに股）、`lineWidth` 4
- 腿に装甲板を `fillRect` で1枚重ね、バルキーな胴体と釣り合わせる
- 足裏 6×3 の大足
- 歩幅を standard の 0.7 倍に縮める（ポーズ座標の水平成分にスケールを掛ける）
- `maxSwing` = 30°（`Math.PI / 6`）、`phaseOffset` = 0.15

### rival（`#CC3333` / speed 1.20）— 好敵手

**プレイヤーと同等の脚**にする。ライバル機はプレイヤーと対等な存在なので、
奇をてらった脚型を与えず、同じ人間型の脚で正面から張り合う見た目にする。

- 脚のパラメータは standard と同一（股関節 奥 7 / 手前 10、`lineWidth` 3、
  足裏 5×2、`maxSwing` 45°、`phaseOffset` 0.2）＝プレイヤーと同じ値
- 膝は前折れの通常関節。逆関節（鳥脚）は採用しない
- 差別化は既存の胴体・頭部ホーン・機体色（`#CC3333`）が担い、脚では行わない

### artillery（`#DDAA00` / speed 0.4）— 4脚クモ歩行

唯一の非2足。現行の四脚シルエットの意図を引き継ぎつつ関節化する。

#### シルエット

クモらしさの核は **膝が胴体より高い位置に跳ね上がる逆へ字**。股関節から一度上外へ
伸び、そこから足首へ下ろす3点ポリライン。膝の Y は約 12（胴体 y=5〜16 の上部）、
足首は Y=22。

- `lineWidth` 2 の細脚、足裏 3×2
- 手前2本を `bodyColor`、奥2本を `headColor`

#### 脚配置

股関節を胴体下に4点、`x = 4, 7, 11, 14`（`y = 16`）。奥・手前を交互に配置する。
配置は前から順に「手前前脚(14) / 奥前脚(11) / 手前後脚(7) / 奥後脚(4)」。
前脚を長め・後脚を短めにして前傾姿勢にする。

#### 歩容（対角トロット）

4本を2グループに分ける。

- **グループA** = 手前前脚(14) ＋ 奥後脚(4)
- **グループB** = 奥前脚(11) ＋ 手前後脚(7)

既存の `walkFrame`（0〜3）をそのまま使い、A は `walkFrame`、B は `(walkFrame + 2) % 4`
を参照して半周期ずらす。各フレームで足先が前後にスイープし、遊脚相（各グループの
参照フレームが 3 のとき）では足先を 2px 持ち上げて踏み替えを見せる。

これにより常に2本が接地・2本が振り出しとなり、カサカサ動くクモの雰囲気が出る。

停止時（`|vx| <= 0.3`）は `walkFrame` が 2 に固定されるため、全脚が中立ポーズで静止する。

#### 空中

`vx` に応じた振り子は共通ロジックを使うが `maxSwing` = 25° と控えめ。代わりに
膝を胴体側へ引き寄せて**脚を丸める**（クモが落下時に脚を縮める挙動）。グループA/B で
縮み量に差をつけ、非対称にする。

#### しゃがみ（狙撃姿勢）

現行の低姿勢を関節版で再現。膝を大きく跳ね上げ、足を左右に広く張って車高を下げた
砲撃スタンスにする。既存の見た目の意図をそのまま引き継ぐ。

## しゃがみ（2足型 3種）

現行は脚を左右に開くだけ。プレイヤーの `_drawCrouchedLegs`
(`src/js/entities/Player.js:586-609`) に相当する「膝を外に折る2本＋足」の関節ポーズに
置き換える。足幅は heavy のみ広め（現行の `spread` 分岐の意図を維持）。

しゃがみ判定は既存のまま `this.crouching || this.burstCount > 0` から導かれる
`crouchOffset > 0` を使う。

## 構成

`EnemyAttacker` に以下のメソッドを持たせる。既存の `draw()` からの呼び出し形は変えない。

| メソッド | 責務 |
|---|---|
| `_drawLegs(ctx, crouchOffset)` | 2足型3種の入口。しゃがみ／空中／歩行を振り分ける |
| `_drawArtilleryLegs(ctx, crouchOffset)` | 4脚型の入口。同じく3状態を振り分ける |
| `_drawJointedLeg(ctx, opts)` | 共通の1本描画。股関節・膝・足首・色・太さ・足裏を受け取る |
| `_legStyle()` | `config.name` から `LEG_STYLES` を引く（未知名は standard） |
| `_hoverSwing()` | 進行方向ローカル `vx` を -1〜+1 に正規化 |

`_drawJointedLeg` は座標をすべて引数で受け取る純粋な描画関数とし、ポーズの決定
（歩行フレーム→座標、振り子回転、クモの脚上げ）は呼び出し側が行う。これにより
2足型と4脚型が同じ描画プリミティブを共有できる。

## 共通化しない判断

Player と EnemyAttacker で脚描画ヘルパーを共通モジュールに切り出すことはしない。

- Player は固定色・固定寸法・単一デザイン、EnemyAttacker は4型ぶんのパラメータを持つ。
  共通化すると引数が肥大化し、どちらの読みやすさも下がる。
- Player の見た目を敵側の変更で壊すリスクを負わない。

共有するのは**手法**であり、コードではない。

## テスト

新規 `tests/attacker-leg-animation.test.js`。既存テストは AI・物理ロジック中心で
描画は未カバーのため、描画専用のテストを追加する。

`moveTo` / `lineTo` / `stroke` / `fillRect` / `translate` / `rotate` の呼び出しを
記録するフェイク `ctx` スタブを用意し、実際の `EnemyAttacker` インスタンスに対して
`draw()` を呼んで記録内容を検証する。

### 2足型（standard / heavy / rival）

1. 接地・移動中に `walkFrame` を 0〜3 と変えると、それぞれ異なる足先座標が出る
2. 空中で `vx` の符号を反転すると足先 X が前後に振れる（符号が反転する）
3. 空中で `vx = 0` のとき、位相ずれにより手前脚と奥脚の足先座標が一致しない
4. rival の脚の頂点座標は standard と一致する（プレイヤー同等であることの検証）
5. heavy の足裏は standard より大きく、歩幅は standard より狭い

### artillery

1. グループA と グループB の足先 X が常に逆位相になる（`walkFrame` 全4値で検証）
2. 接地脚（足首 Y が最下段にある脚）が常に2本以上ある
3. 全脚の膝 Y が股関節 Y より上（＝クモ型の逆へ字）になっている

### 回帰

1. 4型すべてで `draw()` が例外を投げない（接地／空中／しゃがみの3状態 × 4型）
2. 未知の `config.name` を与えても例外を投げず standard 相当で描画される

## 受け入れ基準

- 4型すべてが関節脚で描画され、standard / heavy / rival は2足歩行、artillery は
  対角トロットの4脚歩行をする
- 空中では全型が横速度に応じた振り子挙動を示す
- 各型の既存の見た目の個性（heavy のバルク、rival の機体色とホーン、artillery の低姿勢）が
  失われていない
- rival の脚はプレイヤーと同等に見える
- 新規テストが全件通り、既存テストが1件も壊れていない
- 実機確認はユーザーが実施する
