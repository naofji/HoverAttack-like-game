# セル・オートマトン水流シミュレーション 設計書

日付: 2026-09-06
ブランチ: `feat/water-flow-simulation`

## 目的

地底湖ステージ（4面）において、破壊された壁の穴から水が重力と圧力によって自然に流れ落ち、隣の空間や窪みへ満ちていくリアルな流体挙動を実現する。

## 要件

1. **セル・オートマトン式水量モデル（Mass-Flux）**:
   - 各タイルに水量 `mass`（0〜8、満水が 8）を持たせる。
   - 垂直落下（重力）➔ 斜め滑落（階段）➔ 水平拡散（圧力平衡）の順で質量移動を行う。
   - 質量保存則（総水量が意図せず増減しない）を厳密に保つ。
2. **ピクセル単位の液面高さ連動**:
   - 最上段の水面セルは、水量 `mass` に応じてセル内の液面高さが上下する。
   - 物理判定（`isWaterAtPixel`）および描画（水面線・水深矩形）がその液面高さと正確に連動する。
3. **水面線と波動の完全連動**:
   - 水面波線（サイン波）および爆発・しぶきによる波紋（波動）は、動的な液面高さを基準としてそのまま揺れる。
4. **既存ゲームシステムとの100%下位互換性**:
   - 自機・キャリア・敵・弾の水中減速、グレネード軌道、反射ビームの水面反射、案Bの面取り隙間埋めと完全連携。
   - アクティブセル追跡により、水が静止しているときはシミュレーション計算負荷がゼロになる。

## モジュール構成

1. `src/js/world/waterSimulation.js`:
   - 純粋な流体セル・オートマトン計算関数 `stepWaterSimulation`。
2. `src/js/world/Map.js`:
   - `water` 配列の水量化、ピクセル液面判定 `isWaterAtPixel`、ブロック破壊時の流体トリガー、`update()` でのステップ実行。
3. `src/js/world/environment/water.js`:
   - 水量に応じた矩形描画および動的基準高さを伴う水面波線描画。

## 追記（2026-09-23）: 実装との食い違いの整理

`2026-09-23-water-refactor-design.md` で実装と突き合わせた結果、この設計書を実装に合わせる。

- **「斜め滑落（階段）」は実装されていない。** 実装（`waterSimulation.js`）は
  「垂直落下 → 横方向（落ち口があればそこへ流れ、無ければ層を均す）」の2相で、段差は
  「縁まで横に流れてから落ちる」で表現している。斜めの相は実装し忘れではなく、この
  2相に置き換わったもの。要件1の3段の順序はこの2相に読み替える。
- 要件4の「水が静止しているときは計算負荷がゼロ」は成立している。アクティブ集合の
  漏れ（落ちられる水がアクティブから外れる）は起きないことを
  `tests/water-active-invariant.test.js` で縛っている。
