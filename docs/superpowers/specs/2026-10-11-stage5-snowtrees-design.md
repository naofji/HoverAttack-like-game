# 5面の雪の木 — 設計

日付: 2026-10-11
ブランチ: `feat/stage5-snowtrees`

## 目的

5面（雪と氷）の背景に、雪が積もった木を置く。4面の苔とシダ（`2026-10-11-stage4-plants-design.md`）と同じ作り・同じ壊れ方で、
背は 4面より高めにする。

## ユーザーが決めたこと（2026-10-11）

| 項目 | 決定 |
|---|---|
| 置く面 | 5面の背景 |
| 高さ | アタッカー（24px）の 8割〜3倍 ＝ 見える高さ **20〜72px**（8割は 19.2px → 4px 刻みで 20）。4面の植物より高め |
| 壊れ方 | 4面と同じ（燃えず・誘爆せず・壊せる・弾が止まって欠ける・支えを失えば破片になって落ちる） |
| 種類 | 針葉樹と枯れ木の 2 種 |
| 雪の色 | **岩より明るい青白、ただし地形の雪のふち（`SNOW_CAP_COLOR`）より暗い** |

## 作り方（4面の仕組みを再利用）

- `STAGE_ENVIRONMENTS` の5面に `props: 'snowtrees'`。`Map._generateSnowTrees()` が `Town` に設計図を載せる（`map.town` のまま）
- 設計図の印: `soft: true`（燃えず崩壊の演出なし）＋ `flora: 'snow'`（砕けた粒と穴の縁を雪の木の色にする。`Town` の `_floraOf` と `_flushEffects`）
- 「置けるか」の判定（盤面の中・除外の矩形・岩に埋まりすぎない・重ならない）は `world/town/placer.js` に切り出して 4面と共有した
  （切り出しの前後で 4面・3面の設計図の指紋が同一であることを確かめた）
- 乱数は派生ストリーム（`^0x5E0A71`）だけ。`game.rng` は消費しない（週次の決定性）。基地の部屋にだけ置かない
- 床だけに置く。壁・天井は置かない（天井のつららは別の機能として設計する）

## 種類（`world/town/snowTrees.js`）

- **針葉樹**: 幹の上に枝の段が重なる（高さ 20px で 2 段、72px で 5 段）。段ごとに上側 5〜6 割へ雪、縁は波打ち、下側は針葉の暗い影
- **枯れ木**: 頂まで届く細い幹から、左右の枝が斜め上へ広がり小枝を出す。雪は上を向いた枝の上側だけ、幹の頂に雪帽子。上限は 56px（横に張る分、背が伸びない）
- 天井が低い所は 4面と同じく、置ける高さに切り詰める（20px に満たなければ置かない）。根元は床の上に立つ
  （根元の多角形の右端を 4 ちょうどにしない: かけらの境目に触れて、床の縁で右の 1 かけらが浮いた）

## 色（`palette.js` の `SNOWTREE_COLORS`）

4面の「岩の 0.85 倍以下」は雪には使えない（5面の岩は鋼青で輝度 118。その下の輝度の雪は灰色に濁る）。代わりに:
針葉・幹は遠景の rockLight（39.8）以上・岩より暗い、雪は岩（117.8）より明るく雪のふち（243）より暗い（`tests/snowtrees-palette.test.js`）。

## 実測（今週の5面、seed 384264646、`tools/render-town-scene.mjs --stage 5 --stats`）

**最初の実装時の数値**（密度を上げる前）: 262 本（針葉樹・枯れ木）、設計図 約 34ms ＋ かけらの表 約 15ms、絵 1.3MB、fill 1,598 回・輪 4,602、グレネード 1 発 0.08ms。密度を上げたあとの数値は次の節。
canvas の塗りの時間は node では測れない（実機で面の読み込みを見る）。

## 調整用の定数（`Constants.js`）

`SNOWTREE_HEIGHT`（見える高さの範囲 px）、`SNOWTREE_BARE_SHARE`（枯れ木の割合）、`SNOWTREE_FILL_SCALE`（全体の濃さ）、
`SNOWTREE_GAP`（隣との間隔）、`SNOWTREE_MAX_WIDTH`（木の幅の上限 56px。天井までの空きを測る列の幅。測った最大で、テストが超えないことを縛る）。葉の粒の数は 4面と共通（`PLANT_LEAF_PARTICLES_*`）。

## 追加指示（2026-10-11 その2）: もっとたくさん・倒壊

「もっとたくさん木があった方がいい。木が爆発するのもイマイチなので、破壊されたとき傾きながら下に落ちていく様な感じで倒壊するのが良い」。

### 密度

最初は濃さ 1・間隔 4〜24px で、今週の5面に 232 本（床 100 タイルあたり 8.6 本）。村の外は 10% しか置かないためで、雪の森にしては少なかった。
実測（床 2,702 タイル）: 濃さ 2 → 369、3 → 456、3＋間隔 0〜8px → 534（19.8 本）、5＋間隔 0〜8px → 648（足場がほぼ埋まる）。
**濃さ 3・間隔 0〜8px**（534 本）にした。生成は約 81ms ＋かけらの表約 51ms（以前は約 34 + 15）、絵 2.5MB、fill 3,274 回・輪 9,275。

### 倒壊（`world/town/ToppleTree.js`、`Town._updateTopple`）

- **それまで:** 根元で切れた塊は、落ち始めた最初のコマで床に触れて、その場で雪の粒になって消えていた（爆発したように見える原因）。傾きもほとんど無かった
- **今:** 雪の木の大きな塊（`SNOWTREE_TOPPLE_MIN_CELLS` = 8 かけら以上）は `ToppleTree` になる。**根元（切れ目の中心）を軸に**、立った状態から傾き（傾くほど加速）、
  0.68 秒ほどで横たわり、`SNOWTREE_TOPPLE_LIE_TICKS`（30 tick）かけて薄れて消える。倒れる向きは撃たれた側から離れる向き（岩が壊れたときは位置から決めた向き）
- **幹を撃つと上が丸ごと倒れ、枝葉を撃つと欠けるだけ。** 切り株は残る。小さな塊（枝先の欠片）は今までどおり落ちて砕ける。4面の植物は変えていない
- **軸の作り直し（ユーザー指摘「根本を視点として傾いていくように」）:** 最初は塊の外接矩形の下端の「倒れる側の角」を軸にした（箱が縁で倒れる形。
  枝が床にめり込まず、横たわる角度も求めやすい）が、倒れるにつれて木の根元が切り株から持ち上がり、木が箱のように転がって見えた。今は根元が動かない。
  軸の x は `Town._detach` が決めて渡す: 塊の真下（4 段まで）に残った切り株の真ん中、無ければ木の幹の x（設計図の `footX`）。
  一番下の段のかけらの平均や重心から推すと、幹の横の枝の根元や針葉樹の段の角に軸が外れ、切り株をすり抜けて落ちた（実測 6px ずれ）
- 軸が岩のタイルか、残っている建物のかけら（切り株・隣の木。左右 1px も見る）に乗っていれば軸は動かず傾くだけ、無ければ落ちながら傾く
  （高い所で切れた木は、切れ目の分だけ落ちて切り株に乗り、乗ったまま傾く。切り株が壊れると落ちる）。軸が岩に入り込んだら岩の上に乗せ直す。落ちる軸は建物の上に乗って止まる（欠かさない）
- 横たわる角度は 90°（軸が地面の線の上に水平に寝る）。**根元を軸にすると、傾いた枝や針葉が床より下に回る**（円錐形の針葉樹は横たわると下半分が床にめり込む）。
  Town の層は地形より先に描かれるので、床の下に回った分は地形が上から隠す。足場が薄いと下側が足場の下から見えることがあるが、約 0.5 秒で薄れて消える
  （角を軸にしたときは、90° で止めると先端が約 20px 宙に浮いたので、先端が床に着くまで倒していた。その仕組みは不要になり外した）
- 横たわったとき、雪の粒を木に沿って 3 回に分けて出す（1 か所で一斉に出すと爆発に見える）
- 画面外の判定は `reach`（外接矩形の対角線の 2 倍）で見る（回した先が、元の外接矩形の外へ出るため）
- 倒れる速さ: `ACCEL` 0.005・`SEED` 0.2（角加速度 = ACCEL × (sinθ + SEED)）。90° まで 41 tick（0.68 秒）。0.01・0.3 は 25 tick で、ぱたんと倒れて重みが出なかった
- `tools/lib/pixel-canvas.mjs` の `rotate` を、2 引数の `drawImage` だけ見る形にした（連続写真で倒れる様子を確かめるため）

### 舞う雪（`SnowFlurryParticle`、`Town._spawnSnowFlurry`。ユーザー指定「木が倒れたり削れたりするときに雪が舞う様に」）

- それまでは葉と同じ短命（20〜40 tick）の小さな粒がぱっと散るだけだった。**舞う雪**は、出た勢いで飛んだあと空気抵抗で止まり（`DRAG` 0.95）、ゆっくり左右に揺れながら（`SWAY`）
  落ちて、地面に触れたら消える（ホバーの粉雪 `SnowMistParticle` と同じ消え方）。落ちる速さは `GRAVITY / (1 - DRAG)` = 0.4px/tick に収まる。寿命 50〜90 tick（1〜1.5 秒）、最後の 4 割で薄れる
- **出来事ごとに動きを分ける**（`SNOWTREE_FLURRY_MODES`）。最初は全部「上半分の向きへ 0.5〜2.2px/tick」で、実機で「やや舞い上がりすぎ。弾が当たって欠けるときは控えめに。
  木が倒れるときは雪が振り落とされて、倒れた後に雪が舞うのが理想」と言われて分けた:
  - **hit**（弾・爆風が欠かしたとき。`SNOWTREE_FLURRY_HIT` 5 粒）: 上向きの扇、勢い 0.2〜0.7px/tick（空気抵抗で飛ぶのは最大でも約 14px）。puff の約 1/3
  - **shake**（倒れ始め `START` 14 粒、幅いっぱい。倒れているあいだ 3 tick ごとに木に沿って `TRICKLE` 3 粒）: **下向き**にほとんど勢い無しで落ちる（木が雪を振り落とす）。位置は経過 tick から決め、シミュレーションに乱数を使わない
  - **puff**（横たわったとき `SNOWTREE_TOPPLE_PUFF_PARTICLES` 10 粒を 3 回、木に沿って。そのあと消えるまで 6 tick ごとに `LIE_PARTICLES` 4 粒）: 上半分すべてへ 0.6〜2.0px/tick。倒れた木から**舞い上がる**主役
  1 本が倒れきるまでに約 110 粒。6 粒に 1 粒は針葉の欠片（暗い緑）
- **粒の大きさ**（ユーザー指定「木が倒れた際の雪の粒子を小さめに」）: 倒れる木の雪（shake / puff）は 1px（4 分の 3）か 2px（4 分の 1、`SNOWTREE_FLURRY_BIG_SHARE`）、針葉の欠片は 0.75〜2.25px。欠けたとき（hit）は 2px / 3px のまま。`SNOWTREE_FLURRY_MODES` の `size`
- 色は雪の 3 色のうち明るい側（`SNOWTREE_FLURRY_COLORS`）。手前に出る粒なので木の本体の雪より白くてよいが、地形の雪のふち（`SNOW_CAP_COLOR`）よりは暗く保つ
- 4面の植物は今までどおり（葉の粒）

調整用: `SNOWTREE_TOPPLE_ACCEL` / `_SEED`（倒れる速さ）、`_LIE_TICKS`（横たわって消えるまで）、`_PUFFS` / `_PUFF_PARTICLES`（粒）、`_MIN_CELLS`（倒れる塊の最小）。舞う雪は `SNOWTREE_FLURRY_*`（`_HIT` / `_START` / `_TRICKLE` / `_TRICKLE_EVERY` が数と間隔、`_SPEED` / `_DRAG` / `_GRAVITY` / `_SWAY` / `_SWAY_FREQ` が動き、`_LIFE` が寿命）。
