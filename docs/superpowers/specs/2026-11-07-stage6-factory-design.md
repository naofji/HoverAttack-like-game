# 6面の壊せる工場・基地 — 設計

日付: 2026-11-07

## 目的

3面の「壊せる町並み」と同じ仕組み（床・壁・天井に建つ、撃つと欠ける、支えを失うと崩れる、
爆発物が誘爆する、機体が重なる建物は丸ごと薄くなる前景）を6面（霧の面）にも置く。
3面が「洞窟の中の町」なら、6面は「洞窟の中の工場と軍の基地」。霧の中に工場と基地の影が
浮かび、撃つと鉄骨が赤く焼けて欠け、化学タンクが誘爆する面にする。

### ユーザーが決めたこと（2026-11-07 のブレインストーミング）

| 項目 | 決定 |
|---|---|
| 置く面 | **6面**（`STAGE_ENVIRONMENTS[5]`、霧の面） |
| 置き方・ギミック | **3面と同じ**（床・壁・天井。遮蔽・欠け・崩落・誘爆・前景で薄くなる・町は敵の陣地のルール） |
| 絵柄 | **工場**（天井から吊るしたクレーン、パイプが絡み合った化学工場、工作機械＝ロボットアーム・プレス機・ボール盤・コンベア・コンプレッサー・発電機・縦型タンク・フォークリフトなど）と**基地**（倉庫、格納庫、監視塔、レーダー、白い大きな工場棟）。参考画像はユーザーが4枚提示（工作機械のアイコン集、黄色と灰色の工場機械、黄色いロボットアームとコンベア、白い大きな工場棟と煙突・鉄骨の塔） |
| 爆発物 | **入れる。** 化学タンク・ガスボンベ・ドラム缶など。爆発・誘爆は3面と同じ |
| 金属 | **燃えない。被弾すると赤く変色して欠ける**（爆発物なら爆発する）。**硬さは3面と同じで、1発ごとに欠ける** |

## 全体の形

3面の仕組みをそのまま使う。新しく作るのは「6面の絵柄（設計図を作る関数）」と「金属が赤く焼ける見た目」だけ。

```
Constants.STAGE_ENVIRONMENTS[5].props = 'factory'
Map._generate() → props === 'factory' → _generateFactory()
  → generateTown({ ..., theme: FACTORY_THEME })   ← 置き方は3面の generateTown をそのまま使う
  → new Town(specs, ...)                          ← 壊れ方・火・誘爆・前景・薄くなるのは全部 Town が持っている
```

### generateTown を「絵柄の表」で切り替える（決定: Claude の判断）

今の `generateTown` は A（日干し煉瓦）と C（坑道）の build 関数を直に呼んでいる。これを
「絵柄の表」1行から引く形にし、3面の表（`TOWN_THEME`）と6面の表（`FACTORY_THEME`）を並べる。
CLAUDE.md の「違いは表の1行に出し、手順は1本」に合わせるため。

表の列（案）:

| 列 | 3面（今の挙動） | 6面 |
|---|---|---|
| 広い所の系統（`wide`） | A: `buildAdobeTower` / `buildAdobeWallHouse` / 吊り橋 | B（基地）: 倉庫・格納庫・監視塔・レーダー・工場棟 |
| 狭い所の系統（`narrow`） | C: `buildMiningShack` / `buildScaffoldShack` / 吊り小屋・ランタン | P（工場）: 工作機械・化学タンクと配管 |
| 天井 | 吊り橋・吊り小屋・ランタン | 天井クレーン・配管の束・照明 |
| 爆発物 | A なら油壺の倉、C ならドラム缶・木箱・ボンベ | 化学タンク・ガスボンベ・ドラム缶 |
| 塔どうしの橋 | あり（シバーム） | なし（代わりに渡り廊下／配管橋にするかは builder の判断） |

**3面の町は1棟も変わってはいけない。** 表に移したあと `node tools/trace-map.mjs --compare` で
3面を含む全面の指紋が IDENTICAL（6面だけ町が増える）であることを示す。3面の設計図の並び・乱数の引き方を
変えないこと（村の比率はユーザーが実機で手で詰めた値）。

### 乱数（週の決定性）

3面と同じく、町は生成の最後に作り、`game.rng` を消費しない。派生ストリーム
（`new SeededRNG((this.game.rng.state ^ <6面専用の定数>) >>> 0)`）を建物用と爆発物用に別々に作る。
定数は3〜5面の `0x70E4E5` / `0xB0A3B5` / `0x4F3A57` / `0x5E0A71` / `0x1C1CE5`、7面の `0xFAC17E` / `0xFAC57A` / `0xF0A7E5` と重ならない値にする。
`tests/MapDeterminism.test.js` が通ること。

### 置かない場所

3面と同じ: 基地の部屋（`_reservedRects()[1]`）を避け、最後の敵基地の周りは建てない（quietZones）。
開始の部屋には置く（3面と同じ。面に入った瞬間に工場だと分かるように）。

### 密度

3面の村（`villages.js`）の仕組みをそのまま使い、「工業地帯」の固まりとして読む。
数値も最初は3面と同じ `TOWN_VILLAGE_*`。6面で変えたくなったら、表の行に密度の列を足す
（実機で見てから。最初から別の定数を作らない）。

## 1. 絵柄（6面の設計図）

置き場所: `src/js/world/town/factory.js`（工場 P）と `src/js/world/town/militaryBase.js`（基地 B）。
形の数値は描画専用のパラメータなのでモジュールスコープ（`adobe.js` / `mining.js` と同じ）。
組み立ては `shapes.js` の `rect` / `step4` / `pick` / `normalizeUp` / `mirrorParts`（四角だけで組む。4px 刻み）。
返す形は `mining.js` と同じ `{ kind, w, h, footX, footW, parts }`。

### 床の建物

基地 B（天井の高い広い所に多く）:
- **倉庫**: 平たい箱、波板の壁（縦の継ぎ目）、シャッター、屋上の換気口
- **格納庫**: かまぼこ屋根（4px の段で丸く見せる）、大きな扉
- **監視塔**: 細い鉄骨の脚（細い部品＝すり抜ける）＋上の見張り小屋（厚い壁）、手すり
- **レーダー**: 鉄骨の台＋皿形のアンテナ（段で斜めに見せる）
- **工場棟**: 参考画像4の白い大きな棟。窓の帯、屋上の煙突・ダクト、脇の鉄骨の塔（細い部品）

工場 P（天井の低い狭い所に多く）:
- **ロボットアーム**: 台座＋関節で折れた腕（4px の段で斜め）＋つかみ手
- **プレス機**: 門形の枠、上の台、ラム
- **ボール盤**: 細い柱、頭、台
- **コンベア**: 脚の付いたベルト、上に箱（描くだけ）
- **コンプレッサー／発電機**: 横長の箱、モーター、圧力計、排気管
- **縦型タンク（化学工場）**: 脚の上の円筒（肩を細くして丸く）、絡み合う配管（細い部品）が隣のタンクや床へ伸びる
- **フォークリフト**（任意。builder の判断）

どれも「厚い壁（`solid: true`）＝弾を止める本体」と「細い部品（`solid: false`）＝すり抜けて欠けるだけ」を
3面と同じ考えで分ける（鉄骨の脚・手すり・配管・アンテナの骨・ロボットの腕は細い部品）。

### 壁に付けるもの

- **壁を這う配管とバルブ**: 壁の岩に 4px 打ち込んだ金具から、横・縦に配管が走る（細い部品）
- **足場の上の制御室**: 3面の `buildScaffoldShack` の金属版（鉄の床板・筋交い・窓の付いた箱）

### 天井から吊るすもの

- **天井クレーン**: 天井に埋めたレール（横長）、そこから下がるワイヤーとフック。荷（コンテナ・鉄骨）を吊ったものもある
- **配管の束**: 天井から吊り金具で下がる横の配管が何本も、ところどころで上下に折れて絡み合う
- **工場の照明**: 3面のランタンの置き換え（傘の付いた灯り。弾の黄色と見間違えない暗さ）

### 爆発物

- **化学タンク**（横置き・縦置きの小型）、**ガスボンベ**（束）、**ドラム缶**。部品はすべて `MAT_EXPLOSIVE`・厚い壁
  （3面と同じく「建物1棟まるごと爆発物」）。置き方は3面の `placeExplosives`（床の建物の脇、岩の上だけ）
- 色は3面と同じく「見て爆発物と分かる赤（＋警告の黄色の帯）」。`TOWN_EXPLOSIVE_COLORS` と同じ制約
  （弾の黄色との色の距離 `tests/town-palette.test.js`）

### 色

6面の岩は Cafe Noir `#4B3621`（輝度 57.9）で、3面の DarkGoldenrod（134.9）よりずっと暗い。
3面の規則（壁は「遠景の rockLight 以上、岩の 0.85 倍以下」）を6面の岩で当てはめると **24.0〜49.2** になる。

決定（Claude の判断。実機で見て変える前提）:
- 本体（鋼板・コンクリート・機械の筐体）は 3面の規則をそのまま6面の岩で当てる（24.0〜49.2）。暗い鋼の灰・青灰・
  くすんだ黄（機械の塗装）で、岩の茶色とは色相で離す。参考画像の白い工場棟も、この範囲の「灰」で表す
  （白くすると岩より明るくなり、足場と読み違える）
- 小さな差し色（警告の黄黒の縞、計器、灯り）だけは上限を岩の輝度（57.9）まで許す（3面の `winLit` と同じく
  「光らせない」）。上限は `tests/` で縛る
- 霧は町の上に重なる（`env.drawOverWorld` は町より後）ので、霧の中で影として見える。暗すぎて読めなければ
  上限を上げるのはユーザーの実機判断

色は `palette.js` に `FACTORY_COLORS`（本体・描き込み）として置き、テストは `tests/town-palette.test.js` に
6面の岩で測る版を足す（`STAGE_PALETTES[5]`、`backdropColors(fill, 'fog')`）。

## 2. 材料と壊れ方

### 材料

| 材料 | 何に使う | 燃える | 欠けた縁 |
|---|---|---|---|
| `MAT_METAL`（既存 3） | 機械・鉄骨・配管・タンク・クレーン・波板 | 燃えない（既存の行のまま） | **赤く焼ける（新）** |
| `MAT_CONCRETE`（新 7） | 倉庫・工場棟・管制棟の壁 | 燃えにくい（`TOWN_MATERIALS[1]` 日干し煉瓦と同じ値） | 茶色の焦げ（今のまま） |
| `MAT_EXPLOSIVE`（既存 4） | 爆発物 | 3面と同じ | 3面と同じ（欠けたら爆発） |

- コンクリートを日干し煉瓦（1）と共用しないのは、瓦礫・破片の色（`TOWN_RUBBLE_COLORS`）が土の茶色になるため。
  `MAT_MASK = 0x07` なので 7 が最後の空き番号
- 木（`MAT_WOOD`）は基本的に使わない（パレット・木箱を少し混ぜるかは builder の判断。混ぜれば燃える）
- 硬さは3面と同じ（**1発ごとに欠ける**。ユーザー決定）

### 金属が赤く焼ける（新）

- 金属のかけらが欠けたとき、穴の縁に残った**金属の**かけら（今 `_charEdges` が焦げを重ねる相手）を「熱い」にする
- 熱いかけらは赤熱の色（明るい赤橙）で重ねて描き、`FACTORY_HEAT_COOL`（Constants.js）フレームかけて暗い焼け色へ冷める。
  冷めきったら暗い焼け色を建物の canvas に焼き込み、熱いかけらの一覧から外す
- 金属でない縁（コンクリート）は今の茶色の焦げのまま
- 熱いかけらはその建物の小さな一覧で持ち、毎フレーム描く（建物の canvas は描き直さない。3面の
  「描き直しは欠けたかけらだけ」を守る）。描画は前景の町の層で、薄くなる（`TOWN_OCCLUDE_ALPHA`）にも従う
- 赤熱の色は弾の黄色（`#FFDD33` / `#FFCC00`）と見分けられること（色の距離をテストで縛る）
- 熱は見た目だけ。火はつかない・燃え移らない・爆発物を起こさない（爆発物は今どおり「欠けたら爆発」）
- 崩れ落ちる破片（`FallingPiece`）には熱の色を持ち越さない（Claude の判断。落ちる間に冷めた色で描かれる。短い時間なので目立たない見込み）
- 隣で燃えるコンクリートの火で金属が今の `TOWN_METAL_SCORCH` で茶色く焦げるのは、そのままでよい（Claude の判断。焦げは火の跡で、赤熱は被弾の跡と分けて読める）
- 3〜5面の金属（坑道のトタン・配管）にも同じ見た目を付けるかは**付けない**（3面は今のまま。表の列で6面だけ有効に）

### 3面と同じもの（何も足さない）

遮蔽（厚い壁が弾を止める）、町は敵の陣地（敵の攻撃は自機・母艦が重なる建物だけ欠かす）、支えを失った部分の崩落、
瓦礫、前景に描いて機体が重なる建物を丸ごと薄くする、ダメージバーは最前面。

## 3. 音

最初は3面の音をそのまま使う（崩れる音 `playTownCollapse`、爆発、炎の音は金属なので鳴る場面が少ない）。
金属らしい音（崩れるときの鉄の軋み・かん高い当たり音）は**今回はやらない**。実機で聴いてユーザーが欲しいと言えば別の段で
（足すなら `src/js/audio/sounds/townSounds.js`、A特性で既存の音と相対 dB を縛る）。

## 4. 確かめ方

- `tools/render-town-scene.mjs` を6面でも描けるようにし（今は `props` で分岐している）、PNG で絵柄・色・置き方を見る
- 3面の不変: `node tools/trace-map.mjs --compare` で6面以外の指紋が IDENTICAL
- `tests/MapDeterminism.test.js`、`npm test` 全体
- 6面の設計図のテスト: 置き場所の規則（3面の generate のテストと同じ観点＝岩に埋まる土台、天井との空き、基地の周りに無い）、
  爆発物が赤い・岩の上だけ、色の輝度の上下限、熱いかけらが冷めて焼き込まれる・コンクリートは茶色の焦げ・3面の金属は赤くならない
- 実機の確認はユーザー（ハードリロード Cmd+Shift+R）

## やらないこと

- 金属を硬くする（1発で欠ける。ユーザー決定）
- 3面の町並み・村の比率を変える
- 新しい敵・スコア・霧の索敵の変更
- 金属の専用の音（上の 3. の通り、実機の後で判断）

## builder に任せること

- 各機械・建物の具体的な形と寸法、出る割合（ただし広い所＝基地、狭い所＝工場の傾向は守る）
- 絵柄の表の正確な列の形（3面が1棟も変わらない限り）
- 塔どうしをつなぐもの（渡り廊下・配管橋）を作るか
- フォークリフト・木のパレットを入れるか
- `FACTORY_HEAT_COOL` の初期値と赤熱〜焼け色の色（実機で調整する前提で根拠をコメントに残す）
- 実装の段の切り方（例: 段1 表への移し替え＋3面不変の確認 → 段2 6面の絵柄と置き方 → 段3 コンクリートと赤熱 → 段4 爆発物）

## 追記（2026-11-07、最初の実装を見たユーザーの指定）

| 項目 | 決定 |
|---|---|
| 色 | **全体的にもっと明るく。** 「岩の 0.85 倍以下」をやめ、本体は岩の 1.4 倍（81）〜130、差し色は 150 以下（弾の黄色 輝度 200 前後と見間違えない所まで）。足元をメタルにしたので、岩と競合して足場を読み違える心配が減った |
| 足元の地面 | **工場が建つ地面はできるだけメタル（7面と同じ `BLOCK_METAL`、6発で壊れる）。** 床の建物（爆発物も）の外接矩形 ±1 タイルの床の上面から2段、建物の地面の行まで。同じ高さの床で3タイル以内のすき間はつなぐ（`world/town/factoryGround.js`、`FACTORY_GROUND_*`）。奥が4段以上の岩壁に埋まった見えない足元はそのまま |

足元をメタルにするため、6面だけ町の設計図を地形のキャッシュを焼く前に作る（`Map._prepareFactoryGround`）。設計図は空きか岩かしか
見ないのでメタルにしても並びは変わらず、乱数も引かない（trace-map の rng の指紋は同じ）。メタルは硬いので、工場の下は掘りにくくなる。
地形の絵の基準線（`tests/terrain-shape-drawing-invariance.test.js`）からは6面を外した（2面・7面と同じ扱い）。
| 爆発物の爆発 | **工場は可燃物が多いので派手に。グレネードと同様で周囲にダメージあり。** 粒 `GRENADE_EXPLOSION_COUNT`・半径 `GRENADE_DAMAGE_RADIUS` に `GRENADE_DAMAGE`（敵味方どちらにも）・地形も `GRENADE_BLAST_RADIUS` タイルを `GRENADE_BLOCK_DAMAGE` で壊す（画面の外でも）。爆発の種類は `Constants.js` の `TOWN_EXPLOSIVE_PROFILES` の1行、面は絵柄の表の `explosiveBlast`。3面の町は今のまま（岩は壊さない） |
| クレーンの荷 | **コンテナと鉄骨が落ちたら機体にダメージ**（つららと同じ仕組み。`FACTORY_LOAD_DAMAGE` コンテナ 30・鉄骨 20、1塊1機体1回）。クレーンの設計図が荷の矩形（`heavy`）を持ち、落ちる塊に荷のかけらが入っていれば当たる |
| 爆発物の大きさ | **グレネード級であることを見て分かるよう大きく。** 3面の爆発物の2倍以上の面積・見える高さ 20px 以上（化学タンク 28x24、ボンベ4本 16x28、ドラム缶2本 16x24）。化学タンクには「！」の印。大きくなったぶん置ける所が減り、6シードで 174 → 148 個 |
