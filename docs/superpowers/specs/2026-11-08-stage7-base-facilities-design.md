# 7面: 施設エリアに基地の建物を並べる — 設計

日付: 2026-11-08。親: `2026-11-07-stage6-factory-design.md`（6面の工場・基地）、
`2026-10-31-stage7-facility-metal-design.md`（7面の施設エリア）。

## 何のためか

7面は「洞窟を改造した要塞」。要塞の区画と、区画の外のメタルパネルの施設エリアまではできた。
施設エリアの中に**基地の建物**を並べ、要塞の基地らしさを仕上げる（ユーザーのメモ「7面: 基地の施設」）。

## ユーザーが決めたこと（2026-11-08）

| 項目 | 決定 |
|---|---|
| 置く場所 | **施設エリアの中に、基地の建物が並ぶ** |
| 作り | **6面と似た構造**（3面・6面と同じ「壊せる町並み」の仕組み: 床・壁・天井に建つ、撃つと欠ける、支えを失うと崩れる、機体が重なる建物は薄くなる前景、町は敵の陣地のルール） |
| ベース | 6面は工場だったが、**7面は基地がベース** |
| 見た目 | **全体的にメタリック** |
| 硬さ | 6面より**若干硬め** |
| 爆発物 | **無し**（工場ではないので） |
| 建物 | 私の案（格納庫・司令塔・レーダー・兵舎・通信鉄塔・発電設備・監視所・配管・照明・監視カメラ）に、ユーザーが**フェンス**と**研究室**を追加 |

## 作り

### 1. 仕組みは6面のまま、表に1行足す

`world/town/themes.js` に `BASE_THEME`（7面）を1行足す。置き方は `generateTown` の1本、壊れ方・前景・薄くなるのは
`Town` が持っている（6面の設計と同じ）。新しく作るのは**7面の建物の設計図を作る関数**と、下の「置く場所」「硬さ」だけ。

```
STAGE_ENVIRONMENTS[6].props = 'base'（新しい値）
Map._generate() → props === 'base' → _generateBase()
  → generateTown({ ..., villages: 施設エリアから作る, theme: BASE_THEME, explosiveRng: なし })
  → new Town(specs, { metalHeat: true, chipRadius: 硬さ })
```

### 2. 置く場所: 施設エリアの中だけ

- `generateTown` の `villages`（村の濃さを決める引数）を、**施設エリア（`map.facilityAreas`）から作って渡す**
  （エリアの中心に密な村を1つずつ）。置き方の手順（床・壁・天井の探し方、間隔、村の濃さで数を変える）は3面・6面と同じ
- ただし今の村の濃さは「村の外」でも 0 にならない（`TOWN_VILLAGE_OUTSIDE_FILL`。3面で岩壁にぽつぽつ家が付く分）。
  そこで `generateTown` に**`includeRects`（省略可）**を足し、建物の外接矩形がどれかの矩形に収まるものだけを置く。
  7面は施設エリアを渡す。3〜6面は省略（＝今のまま）
- 要塞の区画（`fortressZones`）・開始の部屋・敵基地の部屋には建てない（施設エリアはもともとそれらを避けている。
  念のため `excludeRects` にも入れる）
- **金属の斜面・階段の上には床の建物を建てない。** 7面の施設エリアには45度の金属の斜面がある。斜面のタイルの上に
  建つと、根元が浮いて見える。床の建物は、足元がすべて四角いタイル（形が `SHAPE_FULL`）の所にだけ建てる
  （壁・天井も、根元が斜面に掛かる所は避ける）
- 乱数は派生ストリーム（`game.rng` を消費しない）。定数は3〜6面・7面の既存のもの（`0x70E4E5` / `0xB0A3B5` /
  `0x4F3A57` / `0x5E0A71` / `0x1C1CE5` / `0xFAC70E` / `0xFAC7B0` / `0xFAC17E` / `0xFAC57A` / `0xF0A7E5`）と重ならない値
- 生成の順は施設エリア（と金属の階段・斜面）の後。建物は地形を変えない（6面の「建物の足元をメタルに」は不要。
  施設エリアの床はもうメタル）

### 3. 建物（`world/town/fortressBase.js` 新規。描画専用の形の数値はこのファイルに置く）

広い所の系統（`wide`）と狭い所の系統（`narrow`）の2つ。どちらも基地。

| 置き場所 | 広い所（wide） | 狭い所（narrow） |
|---|---|---|
| 床 | 格納庫（かまぼこ屋根）、司令塔（窓の帯のある箱形の塔）、大型レーダー（皿形のアンテナ）、**研究室**（白っぽい金属の箱、横長の窓、屋上に排気筒） | 兵舎（低い箱形）、通信アンテナの鉄塔、発電・変電設備、**フェンス**（低く長い金網と支柱） |
| 壁 | 監視所（壁から張り出した窓つきの箱） | 壁沿いの配管とケーブル |
| 天井 | 照明、吊り下げの監視カメラ、ダクト | 照明、配管・ダクト |

- **材料はほぼ金属**（`MAT_METAL`。燃えない、撃たれると縁が赤く焼ける＝6面と同じ `metalHeat`）。6面の倉庫・工場棟のような
  コンクリートの壁は使わない（「全体的にメタリック」）。窓のガラスなど描くだけの細部はそのまま
- 色は7面の要塞のパネル（灰青の金属）と同じ系統。6面の基地（白い工場棟・黄色の機械）と見分けがつくこと。
  色は `palette.js` に7面用の表を足す
- **フェンス**は低く（1〜2タイル）、横に長い。金網は描くだけの細部、支柱と上下の枠を金属のかけらにする
- **研究室**は白っぽい金属の箱（施設の中で一番明るい建物）。爆発物ではない（誘爆しない）
- 爆発物は置かない（`explosive` の列は使わない。`explosiveRng` も渡さない）

### 4. 硬さ: 6面より若干硬め

- 今は全面共通で、弾・ミサイルが当たると半径 4px が欠ける（`TOWN_PROJECTILE_IMPACT` の `chip: 4`）
- 7面は欠ける半径を小さくする。`Town` に7面の倍率（または半径）を渡し、弾・ミサイル・ビームの欠け方にだけ掛ける。
  グレネードの爆風・落ちてくる破片の欠け方も同じ倍率にするかは builder の判断（「若干」なので、まず弾・ミサイルだけ）
- 初期値の案: 半径 4px → **3px**（欠ける面積がおよそ半分強）。実機で見て調整する。定数は `Constants.js`

## 作らないもの

- 爆発物・誘爆（ユーザー決定）
- 施設エリアの外・要塞の区画の中の建物
- 建物の足元の地形の書き換え
- 新しい音（欠ける・崩れる音は町と同じものを使う）

## テストで縛ること

- 7面: 建物はすべて施設エリアの中（外接矩形がエリアに収まる）。区画・開始の部屋・敵基地の部屋に掛からない
- 7面: 床の建物の足元は、すべて四角いタイル（斜面・階段の上に建たない）
- 7面: 建物の数がゼロではない（複数シードで、施設エリアあたりの数の下限）
- 7面: 爆発物が1つも無い
- 7面: かけらは金属が大半（コンクリート・木が無い。ガラスなど描くだけの細部を除く）
- 7面: フェンスと研究室が実際に出る（複数シードのどこかで）
- 硬さ: 同じ位置に弾を1発当てたとき、7面の建物から欠けるかけらの数が6面の設定より少ない
- 3〜6面の町並みは1棟も変わらない（`tools/trace-map.mjs --compare` で 7面以外 IDENTICAL）
- 週次の決定性（`MapDeterminism`）。マップ生成で `game.rng` を消費しない

## 実機で見るところ

| 見るところ | 調整用の定数・場所 |
|---|---|
| 基地らしく見えるか、建物の量 | 施設エリアからの村の濃さ、`BASE_THEME` の行 |
| メタリックに見えるか、6面の基地と見分けがつくか | `palette.js` の7面の色 |
| 硬さ（若干硬いか） | 7面の欠ける半径（新しい定数） |
| フェンス・研究室の形 | `fortressBase.js` |
| 斜面の上に浮いた建物が無いか | — |
