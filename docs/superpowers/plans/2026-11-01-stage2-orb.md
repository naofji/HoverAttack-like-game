# 2面の斜面と Orb 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 2面の洞窟の縁を5面と同じ45度の坂・面取りにし、長い坂を3本盛り、押せて転がり機体にダメージを与え弾を止める壊せない鉱物 Orb を5個置く。

**Architecture:** 地形は既存の形の仕組み（`utils/tileShape.js`）に規則の別名 `caveSlope` を足し、階段は `carveSnowStairs` を面の表の行から呼ぶ。Orb は `entities/Orb.js`（地形との物理と絵）、`utils/orbPhysics.js`（円と地形・円と箱・弾の反射の純関数）、`systems/orbInteractions.js`（機体・弾・地雷・爆風との当たり。`game` を受け取る関数。`blastDamage.js` と同じ作法）に分ける。`main.js` には配列・更新・描画・補間の数行だけを足す。

**Tech Stack:** バニラ ES modules、canvas 2D、`node --test`。

**Spec:** `docs/superpowers/specs/2026-11-01-stage2-orb-design.md`

## Global Constraints

- 2面以外の面の挙動・絵・湧き位置を変えない（基準線テストは level 1 を外して、**変更前のコード**で記録し直す。実装から導かない）。
- 週次の決定性: 地図の生成中に `game.rng` を余分に消費しない。Orb の置き場所は派生ストリーム `new SeededRNG((this.game.rng.state ^ 塩) >>> 0)`。Orb の物理・当たりに `Math.random` を使わない（見た目の粒だけは可）。
- 調整用の数値はすべて `src/js/utils/Constants.js`。Orb の色だけは `entities/Orb.js` のモジュールスコープ（`LEG_STYLES` と同じ例外）。
- コメントは日本語で「なぜ」を書く。数値には根拠（たたき台なら「たたき台・実機で調整」）を残す。
- `git add -A` / `git add .` 禁止。`src/js/main.js` の `debugStartMission` / `debugInvincible` の未コミットの値と、作業ツリーにある母艦押し（Carrier.js・Player.js・Constants.js・main.js・tests/entity-push-terrain.test.js・tests/carrier-push.test.js）の未コミット分を巻き込まない。混在するファイルは自分のハンクだけ `git apply --cached`。`git stash` / `checkout` / `restore` を使わない。
- ソース文字列を grep するテストは書かない。
- 新しい `play*` メソッドを足すなら、引数なしで呼んで例外を投げない。
- テストの全体: `npm test`（約60秒）。ゲート: `npm test -- --test-skip-pattern=湧き位置は重複しない`。

## Review Focus

1. **Orb と壁に自機が挟まる** — 押して Orb が壁に止まったとき、自機は Orb の手前で止まるだけで、岩に入らず、反対へ歩けば離れられる（Task 4 にテスト）。
2. **坂の途中で止まった Orb が震え続ける／平らな床で止まらない** — 速さが閾値未満で 0 になり、位置が毎フレーム変わらない（Task 2 にテスト）。
3. **ゆっくり押しているだけでダメージが入る・押していた自機に転がり戻って毎フレーム当たる** — 閾値未満は押すだけ、当たりは相手ごとに間隔を空ける（Task 5 にテスト）。
4. **速い弾が Orb をすり抜ける** — 1フレームの移動が Orb の直径より長いミサイル・反射ビームでも、線分で当たる（Task 6 にテスト）。
5. **Orb がほかの Orb・敵に乗ったまま、その上で横に滑り続ける／機体の上で弾み続ける** — 機体の上に落ちた Orb は1回当たったあと転がり落ちるか止まる（Task 5 にテスト）。

**Interfaces:**
- Produces（Constants）:
  - `ORB_SIZES = { small: { diameter: 16, mass: 1, pushScale: 0.5, uphillScale: 0.4 }, large: { diameter: 24, mass: 2.25, pushScale: 0.3, uphillScale: 0.15 } }`（mass は面積比 (24/16)²。push/uphill は設計 4.4 のたたき台）
  - `ORB_ROLL_RESISTANCE = 0.08`（px/フレームを毎フレーム減らす。45度の坂の下り成分 GRAVITY·sin45 ≈ 0.21 より小さく、平らな所では負ける）
  - `ORB_STOP_SPEED = 0.05`, `ORB_MAX_SPEED = 6`, `ORB_TERRAIN_RESTITUTION = 0.3`, `ORB_BOUNCE_MIN_SPEED = 1.0`（これ未満の法線速度は弾まず 0）
- Produces（`utils/orbPhysics.js`）:
  - `resolveCircleTerrain(map, cx, cy, r) -> { cx, cy, nx, ny } | null` — 円周 16 点を `map.isSolidPoint` で見て、岩に入った点から中心への向きの和を法線にし、その向きへ 0.5px 刻み（最大 r）で押し出した中心と、単位法線を返す。触れていなければ null。
  - `reflectVelocity(vx, vy, nx, ny, e) -> { vx, vy }` — 法線成分を `-e` 倍、接線成分はそのまま（vn ≥ 0 なら変えない）。
- Produces（`entities/Orb.js`）:
  - `class Orb { constructor(game, { cx, cy, size }) }` — `size` は `'small' | 'large'`。フィールド: `x, y`（左上。`width = height = diameter`、renderInterp・視界カリング用）, `vx, vy, r, mass, spec, onGround, groundNx, groundNy, angle`（絵の回転。転がった距離 / r）, `alive = true`, `pushVx = 0`, `hitCooldown = new Map()`（Task 5）。
  - getter `cx`, `cy`。
  - `pushFrom(dir, speed)` — 次の `update` で、接地面の接線に沿って `dir` 向きへ速さ `speed`。坂を上る向きなら `speed * spec.uphillScale`。押されたフレームは接線方向の重力・抵抗を掛けない（Task 4 が呼ぶ）。
  - `update()` — 重力（`GRAVITY`）→ 押し → 1回の移動が r/2 を超えないよう刻んで動かす → 刻みごとに `resolveCircleTerrain` で押し出し、`reflectVelocity(…, ORB_TERRAIN_RESTITUTION)`（法線速度が `ORB_BOUNCE_MIN_SPEED` 未満なら法線成分を 0）→ 接地（法線の ny < -0.5）なら接線の速さを `ORB_ROLL_RESISTANCE` だけ 0 へ寄せ、`ORB_STOP_SPEED` 未満なら 0 → 速さを `ORB_MAX_SPEED` で頭打ち → `angle += 接線方向に動いた距離 / r`。

**Interfaces:**
- Produces（Constants）: `ORB_PROJECTILE_IMPACT = { bullet: { rule: 'angle' }, missile: { rule: 'angle' }, grenade: { rule: 'bounce' }, beam: { rule: 'bounce' } }`（`townKind` をキーに。設計 4.6）、`ORB_BREAK_INCIDENCE_DEG = 45`（これ未満の入射角は「曲がりが 90度を超える」ので壊れる）
- Produces（`orbPhysics.js`）:
  - `segmentCircleHit(x0, y0, x1, y1, cx, cy, r) -> { x, y, t } | null` — 線分が円に最初に入る点（始点が円の中なら null。発射位置が重なる弾を即消さないため）。

  - `bounce`（グレネード）: 位置を当たった点 + n×0.5、`bounceOffSurface(p, n.x, n.y)`（`utils/grenadePhysics.js`）。
  - `bounce`（反射ビーム）: 位置を当たった点 + n×0.5、速度を鏡映して `setProjectileVelocity`。
  - `angle` で θ < 45°: `p.onTownWall(当たった点)`（マシンガンは火花を出して消える、ミサイルは爆発。岩に当たったときと同じ反応で、名前は町由来だが中身は「固い壁に当たった」）。
  - `angle` で θ ≥ 45°: 位置を当たった点 + n×0.5、速度を鏡映して `setProjectileVelocity`。持ち主（`isPlayerOwned`）は変えない。
- 軌道予測: 予測用の弾にも同じ `sweepProjectileAgainstOrbs` を通す（Orb は止まっているものとして扱う。`game.orbs` を読むだけで動かさない）。
